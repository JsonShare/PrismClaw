# PrismClaw 前端设计规范（排版与视觉）

| 项 | 内容 |
|---|---|
| 版本 | v1.0 |
| 状态 | 已落地 |
| 生效日期 | 2026-11-23 |
| 适用范围 | 聊天主界面、侧栏、右栏、弹窗、空态、轨迹面板、登录页 |
| 实现入口 | `frontend/src/theme/base.css`、`frontend/src/index.css` |

本文档描述字号、行高、字重、图标、间距与 Markdown 排版的唯一标准。新增界面一律取用 `--fs-*` 系列 token，不写死 `px` 字号；确需新档位时先改本文档，再改 token。

---

## 1. 设计原则

1. **基准 14px，中文优先。** 12px 是中文元数据的下限，13px 起才是可读文本；11px 只允许用于纯拉丁或数字的徽章。
2. **层级靠字重、颜色、留白，不靠不断放大字号。** 正文与标题的比值控制在 1.0–1.3。
3. **行高与字号成组定义。** 固定 `px` 行高只能与配套字号同时出现，禁止只改字号不改行高。
4. **盒子与字同步。** 字号缩小后，控件高度、内边距、图标需要一起校准，避免文字浮在过大的容器里。

---

## 2. 字号阶梯

定义位置：`frontend/src/theme/base.css` 的 `:root`。

| token | 值 | 角色 | 典型位置 |
|---|---|---|---|
| `--fs-xs` | 12px | 微标签 | 时间戳、徽章、轨迹键名、token 数、右栏说明 |
| `--fs-sm` | 13px | 辅助 / 导航 | 侧栏、会话标题、菜单、右栏条目、步骤详情、追问 |
| `--fs-md` | 14px | 正文 / 控件 | 消息正文、按钮、输入框、卡片正文 |
| `--fs-lg` | 17px | 区块标题 | 卡片标题、Tab、面板小标题 |
| `--fs-xl` | 20px | 页面标题 | 弹窗标题、设置页标题、空态 Hero |

阶梯间距为 +1 / +1 / +3 / +3：低段紧、高段松，符合“正文密、标题疏”的阅读节奏。

`html` 与 `body` 的 `font-size` 取 `var(--fs-md)`，因此全站 rem 尺寸会随基准联动。

---

## 3. 行高

| 类型 | 行高 | 说明 |
|---|---|---|
| 正文 | 1.8（25.2px） | 中文长文 |
| 辅助文本 | 1.6–1.7 | 侧栏、右栏、菜单 |
| 标题 | 1.35 | h1–h6 |
| 单行控件 | 1.2–1.4 + 固定盒高 | 不使用固定 px 行高配可变字号 |
| 代码块 | 1.55 | — |
| 表格 | 1.6 | 单元格 13px |

**硬约束**：`22px` 固定行高只与 13px 字号组合，`24px` 只与 13–14px 组合。字号变更时必须同步核对，否则行距会从 1.69 漂到 1.83、图标盒与文字失去同轴。

---

## 4. 字重与颜色

| 字重 | 用途 |
|---|---|
| 400 | 正文、表格、辅助文字 |
| 500 | 导航项、h5/h6、表格首列、代码语言标签 |
| 600 | 标题、卡片标题、按钮、表头 |

**中文字重封顶 600。** 苹方族只提供 300/400/500/600 四档，700 会触发浏览器合成加粗，14px 下笔画边缘发虚，并造成“顶栏比 h1 还重”的层级倒挂。700 仅允许用于拉丁品牌字或头像首字母。

文字色三档，层级用色阶表达，**不用 opacity 叠加**：

| token | 用途 |
|---|---|
| `--c-text` | 标题、正文强调 |
| `--c-text-secondary` | 辅助说明、次级信息 |
| `--c-text-tertiary` | 元数据、分区标签 |

次级色再乘 60% 会使有效对比低于 3:1，禁止使用。

## 5. 图标与控件

| 场景 | 图标 | 盒高 |
|---|---|---|
| 微元数据 | 14 | 20 |
| 侧栏 / 列表行 | 16 | 36 |
| 按钮 / 右栏 | 18 | 32 |
| 顶栏 / 空态卡 | 20 | 44 |

- 图标与文字的比例控制在 **1.15–1.35**。
- 图标使用固定 `px`，不随根字号缩放；图标列宽可用 `rem` 保持与文字同轴。
- 主按钮统一 36px，图标按钮 28–32px，输入行 44px。

间距刻度：4 / 8 / 12 / 16 / 20 / 24 / 32。

## 6. Markdown 排版

定义位置：`frontend/src/index.css` 的 `.markdown-message`。

| 元素 | 字号 | 行高 | 字重 | 其他 |
|---|---|---|---|---|
| 正文 | 14 | 1.8 | 400 | 90% 文字色，`text-autospace: normal` |
| h1 | 18 | 1.35 | 600 | 下边框，`-0.01em` |
| h2 | 16 | 1.35 | 600 | 左侧 3px 强调条 |
| h3 | 15 | 1.35 | 600 | — |
| h4 | 14 | 1.35 | 600 | — |
| h5 | 13 | 1.35 | 500 | 次级色 |
| h6 | 12.5 | 1.35 | 500 | 次级色 |
| 表格 | 13 | 1.6 | 400 | 表头 12/600/+0.02em，首列 500 |
| 代码块 | 12.5 | 1.55 | — | 内边距 12/16，头部 30 |
| 行内 code | 0.86em（≈12.0） | 1.45 | — | 必须小于代码块 |
| 引用 | 14 | 1.8 | 400 | 3px 竖线 + 4% 底色 |

块间距：相邻块 14；h1/h2/h3 上间距 26/22/19；h4–h6 上间距 16；标题与其正文 10。

### 6.1 代码块

- 底色：`color-mix(in srgb, var(--c-text) 4%, var(--rich-surface))`，亮色约 `#F6F7F7`。
- 头部：高 30px、透明底、无下边框，左内边距 16px 与代码同轴。
- 语言标签：11px / 500 / 等宽字体，无胶囊底色。
- 边框：中性 `text 9%`，不使用冷蓝 `--c-border`。
- 去除卡片阴影。
- `pre` 内必须 `text-autospace: no-autospace`，否则 CJK 与拉丁之间会插入 1/8em，破坏等宽网格。
- 语法配色：keyword/storage 用紫色（亮 `#8250df` / 暗 `#b392f0`），variable/常量用蓝色；红色只保留给 invalid/deleted，避免与语义色 danger 冲突。

### 6.2 表格

- 表头底色 `text 6%`，字号 12 / 600 / 字距 `0.02em`。
- 斑马纹 `text 3%`，悬停 `accent 7%`。
- 容器不画外框，仅表头与末行使用发丝线。

## 7. 区域规范

| 区域 | 主 | 辅助 | 图标 | 盒高 / 间距 |
|---|---|---|---|---|
| 顶栏 | 14 / 600 | 12 / 80% | 20 | 44 |
| 侧栏导航 | 13 / 500 | 分组标签 12 / 600 + 0.08em | 16 | 行 36，组间距 20 |
| 输入区 | 14 | 13 / 70% | 18 | 行 44，发送 28 |
| 右栏 | 14 / 600 | 12（纯色阶） | 18 | 行 32 |
| 空态三卡 | 标题 14 / 600、条目 14 / 400 | — | 20 | 卡内 12 |
| 弹窗 | 称谓 20 / 600、正文 14 | 13 | 18 | 按钮 32 |
| 轨迹面板 | 12 | 12 | 14 | 行 22，数字 `tabular-nums` |
| rich 视图头 | 12 | 语言标签 11 / 500 | — | 30 |
| 登录页 | 标题 28–30 | 14 | — | 品牌区例外 |

约束：单个控件区域内的字号不超过 3 种、字重不超过 2 种。消息正文按第 6 节的文档阶梯渲染，不受此约束。

---

## 8. 例外与禁止项

**例外**

1. 登录页标题 28/30px：品牌展示区，不参与全局阶梯。
2. 轨迹面板 12px：高密度数据面板，主字号即 12。
3. rich 内容视图（代码/JSON/diff/图片）的 11–12px：仅用于工具条与语言标签。

**禁止**

1. 用 `letter-spacing` 补偿小字号，中文会变散，12px 以下尤其明显。
2. 中文使用 700/800，14px 下合成加粗边缘发灰。
3. 次级文字用 opacity 叠加代替色阶。
4. 只改字号、不改配套行高。
5. 控件区内字号超过 3 种或字重超过 2 种。
6. 可交互文本低于 13px；12px 仅用于非交互元数据。
7. 行内 code 大于代码块。

## 10. 验收清单

- [ ] 控件区字号 ≤ 3 种，字重 ≤ 2 种
- [ ] ≤17px 的中文文本字重 ≤ 600
- [ ] 图标与文字比例在 1.15–1.35
- [ ] 可交互文本 ≥ 13px，12px 仅用于元数据
- [ ] 固定行高与字号成组一致（22px ↔ 13px）
- [ ] 行内 code 小于代码块
- [ ] 次级文字使用色阶，有效对比 ≥ 3:1
- [ ] 亮色与暗色两套层级关系一致
- [ ] 构建通过，现有样式断言全部通过

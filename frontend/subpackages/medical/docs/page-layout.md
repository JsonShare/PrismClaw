## 1. 全局壳：MedicalWorkbenchApp

医疗域整体采用 **侧栏 + 内容区** 两栏布局：

```
┌──────────────────────────────────────────────────────────┐
│ MedicalWorkbenchApp                                      │
│ ┌────────┐ ┌───────────────────────────────────────────┐ │
│ │ 侧栏    │ │ 内容区（mw-cq 容器查询上下文）              │ │
│ │ 190px  │ │ 1fr                                      │ │
│ │        │ │                                           │ │
│ │ 临床业务│ │  ┌─ 抽屉开关条（仅 <lg）──────────────┐   │ │
│ │ ·智能病历│ │  │ [≡] 智能病历                       │   │ │
│ │ ·患者管理│ │  └──────────────────────────────────┘   │ │
│ │        │ │                                           │ │
│ │ 知识库  │ │  ┌─ main（flex-1，内部滚动）─────────┐   │ │
│ │ ·文献知识│ │  │                                   │   │ │
│ │ ·指南知识│ │  │  当前页面组件                       │   │ │
│ │ ·药品知识│ │  │                                   │   │ │
│ │        │ │  └───────────────────────────────────┘   │ │
│ └────────┘ └───────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

### 关键结构

| 元素 | CSS/行为 | 说明 |
|------|----------|------|
| 外层容器 | `flex gap-3 p-3 sm:p-4 lg:p-5 h-full` | 响应式内边距 |
| 侧栏 `<aside>` | `w-[190px]`，`<lg` 时 `absolute` + 抽屉（默认 `-translate-x-full`） | 宽屏常驻，窄屏滑出 |
| 遮罩 | `mw-scrim lg:hidden absolute inset-0 z-30` | 抽屉打开时的半透明背景 |
| 抽屉开关 | `lg:hidden relative z-40`，展开时 `pl-[202px]` 避开抽屉 | 汉堡/X 按钮 + 当前页面名 |
| 内容列 | `flex-1 min-w-0 min-h-0 flex flex-col` | 占满剩余空间 |
| `<main>` | `mw-cq flex-1 overflow-y-auto mw-scroll` | 容器查询上下文 + 细滚动条 |

### 导航路由

侧栏分组导航，5 个页面 key：

- **临床业务**：`records`（智能病历）、`patients`（患者管理）
- **知识库**：`literature`（文献知识库）、`guidelines`（指南知识库）、`drugs`（药品知识库）

特殊路由：`PatientDetailPage` 不在侧栏导航中，由 `isPatientDetail && route.patientId` 条件渲染，其他页面组件通过 `onOpenPatient(id)` 跳入。

### CSS Grid 定义

```css
/* v3-records.css — .mw-v3 .main-cols （唯一真值） */
.mw-v3 .main-cols {
  flex: 1; display: grid; min-height: 0;
  grid-template-columns: minmax(0, 0.95fr) minmax(0, 0.95fr) minmax(0, 1.4fr);
}
```

**按比例弹性，不设断点。** 可用宽度同时受「待指派」侧窗（360px）与域导航
（192px）挤压，任何视口断点都会被击穿 —— 实测容器 691px 时固定式 300/300/1fr
会把详情栏压到 91px、正文整段竖排不可读。比例式在宽容器下几乎等同原设计
（1062px → 294/294/474），窄容器下详情栏仍保住 300px 以上。

> 本节原记为 `.mw-cols-records`（240/340/1fr + 640/1080 容器断点）。
> 该类已随 v3 改版废弃并从 `medical.css` 删除：实现改用 `.main-cols`，
> 且断点方案被「比例弹性」取代。文档与实现同源，避免分叉。

### 拖拽机制

| 参数 | 值 |
|------|-----|
| `chatRatio` 默认值 | `0.42`（右栏占视窗 42%） |
| 最小值 | `0.25` |
| 最大值 | `0.55` |
| 拖拽方向 | 向左拖=右栏变宽（`delta = startX - ev.clientX`） |
| 实现方式 | `document` 级 `mousemove/mouseup`，`body.cursor='col-resize'` + `userSelect='none'` |
| CSS 变量 | `--detail-left: ${(1-ratio)*100}%` / `--detail-right: ${ratio*100}%` |

### 拖拽把手

桌面端（≥768px）在两栏之间渲染 `.layout-drag-handle`（1px 宽 + 6px grip 浮层）：

- 1px 发丝竖线（`::before` 伪元素，`background: var(--c-border)`）
- 悬停：竖线变为 40% 品牌蓝 + grip 边框变为 40% 品牌 + 背景 8% 品牌蓝
- 按下：竖线 60% 品牌蓝 + grip 边框 60% 品牌 + 背景 12% 品牌蓝
- 三个 `grip-dot`（3×3px 圆点）竖向排列

移动端（<768px）：把手隐藏，右栏变为底部面板（`max-height: 50vh` + 顶部分隔线）。

## 6. 设计体系

### 配色

全部颜色取自主题 token，随 `data-theme` 明暗翻转：

| 用途 | token | 说明 |

### 字体音阶

| token | 大小 | 用途 |
|-------|------|------|
| `--fs-xs` | 11px | 日期/辅助/标签/页码 |
| `--fs-sm` | 13px | 标签/描述/按钮 |
| `--fs-md` | 15px | 正文/列表项 |
| `--fs-lg` | 18px | 卡片标题 |
| `--fs-xl` | 22px | 页面标题/关键数值 |

### 卡片体系

- 白底 + `1px solid var(--c-border)` 发丝边框 + `rounded-lg`
- 标题颜色由 `tone` prop 决定（accent/danger/warning/success/默认主色）
- 异常值行：大号加粗 + 竖条 + 红/橙色 + 箭头（↑↓）

### 胶囊/Pill

- `border-radius: 999px` + `padding: 2px 10px`
- 颜色由 `tone` 映射到 `--mw-tone` / `--mw-tone-soft`

### 分隔线

- `mw-divider`：`1px dashed var(--c-border)` 虚线发丝
- `mw-rule`：`1px solid var(--c-border)` 实线，弹性宽度

### 滚动条

- `mw-scroll`：4px 宽细滚动条，`scrollbar-color: var(--c-border-strong) transparent`

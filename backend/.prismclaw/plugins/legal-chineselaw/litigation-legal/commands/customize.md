# 自定义争议诉讼配置

## 读取当前配置

读取 `~/.prismclaw/plugins/legal-chineselaw/litigation-legal/PRISMCLAW.md`（以及上一层的 `~/.prismclaw/plugins/legal-chineselaw/company-profile.md`），获取当前自定义配置。如果插件配置不存在或仍包含 `[PLACEHOLDER]` 值，提示用户先运行冷启动访谈。

## 显示可自定义项

列出所有可自定义项及其当前值：

- **公司/你是谁**——名称、行业、司法管辖区（省份+法院级别）、阶段、执业设置 *(在所有 12 个插件中共享——更改通过 `company-profile.md` 传递)*
- **Practice role**——内部法律顾问 / 外部法律顾问 / 独立 / 诊所
- **立场**——原告 / 被告 / 混合，以及任何姿态细微差别（集体诉讼被告、监管执法被告、商业原告等）
- **风险校准**——什么算作传入催告、调查令或新事项的高/中/低风险；升级触发器
- **业务格局**——经常对手、友好和不友好论坛、需要了解的法官、现有的外部律师关系
- **内部风格**——文书风格、证人陈述格式、律师函模板、询问提纲结构、证据保全模板
- **严重性词汇映射**——您如何在客户/内部/面向法院的输出中转换严重性标签
- **人员**——事项负责人、内部团队、按事项类型的外部律所、升级链
- **工作流**——事项工作区、投资组合日志、外部律师状态节奏、证据保全刷新节奏
- **集成**——文档存储（企业协作云盘/钉钉文档/本地） / 电子归档 / 日历 / 企业协作/钉钉通知、备用方案

## 修改配置

询问用户想修改什么，然后修改对应配置项。展示当前值，询问新值，说明下游影响，确认后写入配置。

示例：
- *立场从混合变为仅被告：* "`/matter-intake` 将停止询问原告方问题。`/demand-draft` 仍可适用于被告方诉讼前要求，但起始框架将不同。"
- *风险校准收紧高风险阈值：* "更多传入催告和调查令将通过 `/matter-briefing` 和 `/oc-status` 路由。"
- *新增知识产权事项的常设外部律师：* "`/oc-status` 将在 IP 标记事项的每周扫描中包括此律所。"

对于共享档案更改（公司名称、行业、司法管辖区、执业设置、阶段）：写入 `~/.prismclaw/plugins/legal-chineselaw/company-profile.md` 并注意影响范围。修改后保存。

## 关闭

确认修改完成，告知用户如何恢复默认。

## 护栏

- **永不删除章节。** 如果用户想要从范围中"删除"事项类型，提供将其标记为 `[Not currently handled]` 并说明摄入路由的变化。
- **标记内部不一致。** 如果更改会使档案不一致（例如，仅原告方 + 仅被告方外部律师名单；或"大量"投资组合 + 未配置事项工作区），请标记紧张关系。
- **标记护栏降级。** `/demand-draft` 上的和解通信保密检查（中国法下无直接等价于FRE 408的规则，但调解程序中的陈述受民诉法司法解释第107条保护）、事项输出的特权标题、来源归因标签以及引用权限上的 `[verify]` 标签是承重的——不要删除。`[review]` 标记和"未经律师审查不得提交"框架是承重的。
- **一次更改一项。** 不要重新询问整个访谈。

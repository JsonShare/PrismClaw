# 场景适配卡

同一套七标签与一致性审计，落到不同病种要问不同的问题。按病例类型取用对应卡片，不要拿一张通用清单套所有病例。

---

## A. 肿瘤病例

### A1 必查字段

| 维度 | 要提取的内容 | 常见缺失 |
|---|---|---|
| 病理 | 组织学类型、分化、免疫组化、分子分型（如 EGFR/ALK/KRAS/BRAF/HER2/MSI/TMB/PD-L1） | 只写「腺癌」，无分子结果 |
| 分期 | TNM 版本（第 8 版）、临床/病理/影像分期、是否已行 PET-CT | 写「晚期」但无 T/N/M |
| 治疗线 | 一线/二线/后线、方案全称、周期数、起止日期、减量或延迟原因 | 只写「化疗过」，无方案与周期 |
| 疗效 | 评价标准（RECIST 1.1 / iRECIST / RANO / PERCIST）、评价日期、靶病灶径线变化 | 写「有效/稳定」但无径线与日期 |
| 不良反应 | CTCAE 分级、发生时间、处理、是否导致停药 | 只写「耐受良好」 |
| 结局 | 末次随访日期、生存状态、后续计划 | 随访日期与结论时点错位 |

### A2 常见材料缺陷

- **分期版本不明**：不同版本 TNM 的分期结论不同，必须确认版本，否则分期结论无法比较。
- **疗效评价时点与影像日期错位**：把 3 个月前的影像当作本次评价依据。
- **把「稳定」写成「有效」**：SD 不是缓解，PR 需要径线缩小 ≥30% 并有基线对照。
- **免疫治疗后的假性进展被当作进展**：需 iRECIST 复核，且要有后续影像确认。
- **不良反应分级缺依据**：CTCAE 分级要能对应到具体指标（如中性粒细胞绝对值），不能只写「3 级骨髓抑制」。

### A3 复盘时要问的问题

1. 分期依据的影像与病理是否同期？有无分期迁移？
2. 每个治疗线的**停药原因**是什么——进展、毒性、患者意愿还是经济因素？
3. 疗效评价是否使用同一标准、同一测量者、同一影像方法？
4. 分子检测是否在治疗决策前完成？结果是否影响了方案选择？
5. 是否评估过临床试验入组条件？若未入组，原因是什么（可接 `clinical-trial-lookup`）？
6. MDT 结论与实际执行是否一致？不一致处有无记录理由？

## B. 慢病病例

### B1 必查字段

| 维度 | 要提取的内容 | 常见缺失 |
|---|---|---|
| 诊断 | 诊断标准依据、分级/分期、病程起點 | 只有诊断名，无分级与起病时间 |
| 控制水平 | 近 3–6 次关键指标及日期（血压、HbA1c、LDL-C、eGFR、UACR） | 只记单次值，无趋势 |
| 用药 | 药名、剂量、调整时间与理由、依从性评估方式 | 只写「规律服药」，无依从性依据 |
| 并发症筛查 | 眼底、尿微量白蛋白、颈动脉超声、神经传导、心超 | 长期未筛查，或筛查结果未记录 |
| 合并症与相互作用 | 多病共存的用药冲突、肝肾功能对剂量的影响 | 多科处方未合并审视 |
| 随访 | 计划间隔、实际间隔、失访原因 | 计划写了但无执行记录 |

### B2 常见材料缺陷

- **单点数值冒充控制水平**：一次血压 138/86 不能代表达标，要看家庭自测或动态血压的均值与达标率。
- **缺基线**：没有起始值，无法判断变化幅度与速度。
- **靶器官损害未评估**：只盯指标数值，没查眼底/肾脏/心脏，风险分层不完整。
- **剂量调整无理由记录**：加了药但没写为什么，复盘时无法判断是达标驱动还是副作用驱动。
- **依从性无客观依据**：仅凭患者自述，未查配药记录或用药提醒数据。

### B3 复盘时要问的问题

1. 诊断是否符合现行标准？分级是否准确？
2. 控制指标用的是哪几次、哪段区间？是否包含家庭自测/动态监测？
3. 每次用药调整的**触发原因**是什么？
4. 并发症筛查的**时间间隔**是否符合指南要求？漏了哪项？
5. 多病共存时，处方之间是否存在重复、冲突或相互抵消？
6. 失访或未达标时，有没有做过原因分析（经济、认知、副作用、方案复杂度过高）？

## C. 质子治疗与放疗病例

### C1 必查字段

| 维度 | 要提取的内容 | 常见缺失 |
|---|---|---|
| 诊断与分期 | 同 A1；放疗目的（根治/辅助/姑息/再程） | 未写放疗目的 |
| 靶区 | GTV/CTV/PTV 定义、勾画依据、是否融合 MR/PET | 只写「照射病灶」 |
| 剂量 | 处方剂量 **Gy(RBE)**、分割次数、单次剂量、总疗程 | 把 Gy 与 Gy(RBE) 混写 |
| OAR 限量 | 关键器官 Dmax/Dmean/Vx，与实际计划值的对比 | 无 DVH 参数 |
| 计划与 QA | 计划技术（IMPT/PSPT/VMAT）、束流角度、摆位误差、QA 结果 | 无 QA 记录 |
| 反应 | 急性（≤90 天）/晚期（>90 天）反应，RTOG/EORTC 或 CTCAE 分级 | 只写「耐受良好」 |
| 随访 | 首次评估时点、影像方法、是否与临床反应时序匹配 | 随访影像与症状时点错位 |

### C2 质子特有注意点

- **剂量单位必须写清**：质子处方剂量通常以 `Gy(RBE)` 表达（RBE 取 1.1），与光子 `Gy` 混写会导致剂量比较错误。发现混写直接标 `[资料冲突]`。
- **束流角度与摆位不确定性**：质子对解剖变化（体重下降、腔隙积气、肿瘤缩小）更敏感，复盘要查是否有治疗中 CT 复核或自适应计划。
- **儿童与年轻患者的二次肿瘤风险**：属于长期随访节点，不应只记录急性反应。
- **再程放疗**：必须核对既往剂量累积，尤其 OAR 的累计受限剂量。
- **质子与光子的可比性**：不要用光子计划的 DVH 直接对比质子计划，需注明计划类型与优化目标差异。

### C3 常见材料缺陷

- 靶区命名不一致（GTV-1 / GTV1 / 原发灶混用），导致无法追溯对应剂量。
- 只有处方剂量，没有实际计划达到的 OAR 剂量，无法判断计划质量。
- 急性反应按 CTCAE、晚期反应按 RTOG，两套标准混用且未注明。
- 随访影像早于 3 个月就判定疗效，未考虑放射性改变与假性进展。
- 缺失治疗中断记录：因毒性或机器故障中断的天数未记录，影响生物有效剂量判断。

### C4 复盘时要问的问题

1. 放疗目的是根治还是姑息？与分期、体能状态是否匹配？
2. 靶区勾画依据了哪些影像？有无病理/分子信息辅助？
3. 处方剂量与分割方式是什么？实际 OAR 剂量是否在限量内？
4. 治疗期间有无解剖变化需要自适应？有无中断？中断多久？
5. 急性与晚期反应分别用什么标准分级？
6. 随访影像时点与临床反应是否一致？有无需要鉴别放射性改变与进展？

## D. 跨病种通用追问

无论哪类病例，最后都补这三问：

1. **这个决策当时有没有替代方案？为什么没选？**（判断是主动选择还是条件限制）
2. **如果重来一次，哪个节点最值得改？**（避免把事后结果当作当时可预见）
3. **材料里最缺的那一项，会不会改变结论？**（决定这份复盘的可信度上限）

# 临床病例结构化复盘

## 定位

把一份或多份已脱敏的病例材料，整理成**能被专家复核、能被 MDT 讨论、能作为教学材料**的结构化记录。

核心不是「给出诊断建议」，而是**把材料里的事实、推断、证据、矛盾和缺口分开摆清楚**，让临床团队看到决策节点在哪里、依据是否充分、还缺什么。

本技能不产出诊疗结论。

## 三条硬边界

1. **隐私闸门**：仅处理已脱敏内容。发现姓名、住院号、门诊号、身份证号、联系方式、精确住址、罕见病+精确日期等可识别组合时，停止复述并要求先脱敏。
2. **急症闸门**：若材料或对话显示正在发生的危急情况——持续胸痛、显著低血压或低灌注、意识改变、严重呼吸困难、活动性大出血、恶性心律失常、心跳呼吸骤停、快速进展的多器官功能障碍、肿瘤急症（上腔静脉综合征、脊髓压迫、肿瘤溶解综合征、中性粒细胞缺乏伴发热）——先输出简短升级提示，要求立即启动线下急救或院内快速反应，再决定是否继续。**急症闸门优先于完整输出模板**，必要时只输出升级提示、已知事实、最关键缺失信息和边界声明后停止。
3. **决策边界**：不输出患者特异性诊断定论、处方、剂量、输注速度、器械型号、手术指征、放疗靶区或处方剂量、临床试验入组裁决。这些只作为「需要团队确认的问题」列出。

## 七类证据标签（强制）

每个关键表述必须带标签，不得混用：

| 标签 | 含义 | 典型误用 |
|---|---|---|
| `[病例事实]` | 材料直接记录的症状、体征、检查值、干预、结局 | 把作者判断写成事实 |
| `[作者解释]` | 原作者对病因、诊断、机制、策略、疗效的判断 | 当作已证实结论 |
| `[独立证据]` | 已核对的现行指南、共识或原始研究（须可溯源） | 凭记忆编造指南名或推荐等级 |
| `[资料冲突]` | 同一材料内部日期、单位、剂量、分期、结局、引用互相矛盾 | 只挑一个版本采用 |
| `[未核实]` | 无可靠原始出处，或仅二手转述 | 当作事实继续推演 |
| `[未执行]` | 材料中讨论或建议但未实际实施的方案 | 写成「已用某方案治疗」 |
| `[缺失]` | 足以改变判断、但材料未提供的信息 | 用常识补齐而不标注 |

单病例只能说明「这份材料记录了什么」，不能推出普遍疗效、确定因果或适用于同类患者。任何外推都必须显式标注为作者推断。

## 工作流

### 第 1 步：确认输入合同

开工前先说清四件事，缺一项就问：

- **任务类型**：事实整理 / 决策复盘 / MDT 准备 / 教学起草 / 引用核验
- **使用场景**：回顾性 / 模拟教学 / 正在诊疗 / 无法判断
- **材料范围**：实际提供了哪些病历、检验、影像、病理、用药、手术/放疗记录、随访
- **目标问题**：想复盘什么，而不是笼统的「分析一下」

资料不足时继续做可完成部分，缺项标 `[缺失]`，**不得补造**。

### 第 2 步：过双闸门

先查隐私，再查急症。命中即按上面的硬边界处理。

### 第 3 步：冻结事实并做一致性审计

按时间轴逐项提取，边提边查六类不一致：

| 审计项 | 要查什么 |
|---|---|
| 日期 | 症状起点、检查、干预、结局的先后是否自洽；有无「术后第 3 天」与具体日期矛盾 |
| 单位与数值 | 检验值单位是否合理（如 CRP 写成 mg/ml 必错）；有无缺参考范围 |
| 剂量与疗程 | 入院/住院/出院剂量是否突变；疗程与方案是否匹配 |
| 诊断强度 | 作者结论是否超出材料支持的强度（「可能」被写成「确诊」） |
| 结局与随访 | 摘要与正文的转归是否冲突；随访时长与结论是否匹配 |
| 引用与数字 | 指南题名、年份、DOI、推荐等级、风险数字是否真实对应 |

每条冲突都要**并列写出 A、B 两个表述**，不要替材料选边。

### 第 4 步：区分「讨论过」与「做过」

单独列出未执行方案、未核实风险数字、错配引用。这一栏不得埋进一般讨论——它往往是复盘里最容易被误读成事实的部分。

### 第 5 步：画问题地图

- **当前最危急问题**：按时间紧迫性排序，附判定依据与 `[缺失]`
- **主要矛盾**：列出候选、支持证据、反对或不完整证据，不强行收敛成一个结论
- **决策节点**：标出「做了选择」的关键时点，写清当时的可选方案、实际选择、可获得的依据、当时缺什么
- **可改进点**：流程层面（是否该做的检查没做、该等的会诊没等、该记录的没记）

### 第 6 步：按病种取用场景适配卡

读 `references/scenario-adapters.md`，按肿瘤 / 慢病 / 质子放疗选用对应的复盘要点，避免用同一套问题清单套所有病种。

### 第 7 步：输出前质量门

逐条自检，任一不通过就回去改：

- [ ] 每条关键表述都有标签
- [ ] 所有冲突都并列呈现，没有替材料选边
- [ ] 未执行方案单独成栏
- [ ] 没有输出诊断定论、处方、剂量、靶区或手术指征
- [ ] 每个 `[缺失]` 都说明了「为什么它会影响判断」
- [ ] 引用可溯源；核不到的写 `[未核实]`，不编造
- [ ] 单病例结论没有外推为普遍规律
- [ ] 中医药内容与现代指南证据分开标注

## 输出

默认用 `references/output-template.md` 的九段结构。用户只要口头结论时，可压缩为「一句话摘要 + 最危急问题 + 三个待确认问题」，但标签体系不能省。

文档较长时，先给一页结论，再展开明细表。

## 与其它技能的关系

- 需要按临床试验入组筛选 → `clinical-trial-lookup`
- 需要把病例原文抽成结构化字段 → `clinical-note-extract`
- 需要出治疗计划文本 → `treatment-plan-writer`
- 本技能只做复盘与结构化，不产出上述三类交付物的最终结论

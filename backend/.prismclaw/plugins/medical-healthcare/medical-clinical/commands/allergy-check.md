# /allergy-check

## 目的

在处方前或用药前检查患者过敏史与目标药物之间的交叉反应风险，识别潜在的过敏冲突并提供安全的替代建议。

## 执行步骤

1. 读取 `~/.prismclaw/plugins/medical-healthcare/medical-clinical/PRISMCLAW.md` 获取执业档案。
2. 获取以下信息：
   - **患者过敏史**：已知过敏原、严重程度、反应类型（皮疹/过敏性休克/血管神经性水肿等）
   - **目标药物**：需要检查的药品名称、剂量、给药途径
3. 调用 `allergy_check` 工具（MCP）进行三级冲突检测：

   ### 3.1 DIRECT — 直接过敏
   - 目标药物是否在患者已知过敏原列表中
   - 检查药物活性成分、辅料是否与过敏原直接匹配

   ### 3.2 CLASS — 同类交叉过敏
   - 目标药物是否属于与过敏原相同的药物类别
   - 主要类别映射：
     - **青霉素类** → 青霉素 G、氨苄西林、阿莫西林、哌拉西林等
     - **头孢菌素类** → 头孢克洛、头孢呋辛、头孢曲松、头孢他啶等
     - **磺胺类** → 磺胺甲恶唑、磺胺嘧啶、磺胺多辛等
     - **NSAIDs（非甾体抗炎药）** → 阿司匹林、布洛芬、萘普生、双氯芬酸等
     - **阿片类药物** → 吗啡、羟考酮、芬太尼、可待因等

   ### 3.3 CROSS-REACTIVE — 跨类交叉反应
   - 评估药物类别之间的交叉过敏风险
   - 关键交叉反应映射：
     - **青霉素 ↔ 头孢菌素**：交叉过敏发生率约 5-10%，头孢菌素在青霉素过敏患者中需谨慎使用（尤其是头孢克洛、头孢克肟等侧链相似者）
     - **青霉素 ↔ 碳青霉烯类**：亚胺培南、美罗培南交叉过敏风险存在
     - **磺胺类 ↔ 芳香胺类**：磺胺类与局部麻醉药（利多卡因等）的交叉反应
     - **NSAIDs ↔ 阿司匹林**：NSAIDs 诱发的哮喘/过敏反应与阿司匹林交叉
     - **阿片类 ↔ 其他阿片激动剂**：吗啡与可待因、曲马多之间的交叉过敏

4. 根据三级检测结果生成过敏风险报告。
5. 如检测到冲突，提供替代药物建议。

## 安全声明

本过敏检查基于药物分类交叉反应规则，不涵盖所有可能的过敏反应。患者个体过敏反应差异大，最终用药决策须结合患者具体过敏史和皮试结果（如适用）由执业医师作出。对于青霉素、头孢菌素等高风险类别，建议给药前进行皮试。

> 注意：本回复由 AI 辅助生成，仅提供一般性参考框架，不构成医疗建议或诊断。具体医疗问题，请咨询持有效执业证的医师。

# /vital-signs

## 目的

记录和分析患者生命体征，识别异常趋势，为临床决策提供数据支持。

## 执行步骤

1. 读取 `~/.prismclaw/plugins/medical-healthcare/medical-clinical/PRISMCLAW.md` 获取执业档案。
2. 获取生命体征数据：
   - 心率（HR）
   - 血压（BP）- 收缩压/舒张压
   - 血氧饱和度（SpO2）
   - 体温（Temp）
   - 呼吸频率（RR）
   - 疼痛评分（Pain）
   - 意识状态（GCS/AVPU）
3. 与正常范围和患者基线对比。
4. 标记异常值：
   - 🔴 严重异常——需要立即干预
   - 🟠 中度异常——需要关注
   - 🟡 轻微异常——监测
5. 生成趋势分析（如有历史数据）。
6. 输出结构化报告。

## 输出格式

```
# 生命体征报告

## 患者：[XXX]
## 时间：[YYYY-MM-DD HH:MM]

### 当前体征
| 参数 | 数值 | 单位 | 状态 | 趋势 |
|---|---|---|---|---|
| 心率 | [XX] | bpm | 🟢 | → |
| 收缩压 | [XXX] | mmHg | 🟡 | ↑ |
| 舒张压 | [XX] | mmHg | 🟢 | → |
| 血氧 | [XX] | % | 🟢 | → |
| 体温 | [XX.X] | °C | 🔴 | ↑↑ |
| 呼吸频率 | [XX] | /min | 🟢 | → |
| 疼痛 | [X]/10 | | 🟡 | ↑ |

### 异常标记
- 🔴 体温升高 [XX.X°C]，高于正常范围
- 🟡 收缩压偏高 [XXX mmHg]

### 建议
- [建议措施]
- [随访时间]
```

## 安全声明

生命体征数据为临床参考。异常值的临床意义须结合患者整体状况判断。

> 注意：本回复由 AI 辅助生成，仅提供一般性参考框架，不构成医疗建议或诊断。具体医疗问题，请咨询持有效执业证的医师。

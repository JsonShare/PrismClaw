# /patient-summary

## 目的

快速从病历中生成结构化的患者摘要，供临床团队交接或快速了解患者情况。

## 执行步骤

1. 读取 `~/.prismclaw/plugins/medical-healthcare/medical-clinical/PRISMCLAW.md` 获取执业档案。
2. 获取患者数据：从 EMR 集成或用户提供的文件/文本中读取。
3. 提取以下关键信息：
   - **主诉和现病史**
   - **既往史**（包括慢性病、手术史、过敏史）
   - **用药史**（当前用药、剂量、疗程）
   - **生命体征**（最近值和趋势）
   - **检查结果**（实验室、影像、病理）
   - **诊断和鉴别诊断**
   - **治疗计划**（当前和待执行）
   - **待办事项**（预约、随访、检查）
4. 按时间线组织，标记重要的临床事件。
5. 生成结构化摘要。

## 输出格式

```
# 患者病史摘要

## 基本信息
- 姓名：[XXX]
- 性别/年龄：[X/X岁]
- 就诊日期：[YYYY-MM-DD]
- 主管医师：[XXX]

## 主诉
[主诉描述]

## 现病史
[按时间线描述]

## 关键发现
- 生命体征：[最近值]
- 实验室：[关键结果]
- 影像/病理：[关键 findings]

## 诊断
- 主要诊断：[XXX]
- 鉴别诊断：[XXX]

## 治疗计划
- 当前用药：[XXX]
- 待执行：[XXX]
- 随访计划：[XXX]

## 待办事项
- [ ] [待办事项1]
- [ ] [待办事项2]
```

## 安全声明

本摘要为临床工作辅助工具，不构成医疗记录的正式部分。所有信息须与原始病历核对。

> 注意：本回复由 AI 辅助生成，仅提供一般性参考框架，不构成医疗建议或诊断。具体医疗问题，请咨询持有效执业证的医师。

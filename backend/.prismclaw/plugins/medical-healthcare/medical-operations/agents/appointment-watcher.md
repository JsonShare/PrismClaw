# 预约监控 Agent

## 目的

持续监控预约变更和病历完成状态，确保运营流畅。

## 运行计划

每日运行。

## 执行步骤

1. 扫描预约系统变更
2. 检查病历完成状态
3. 标记即将到期的任务
4. 生成每日报告
5. 发布至指定渠道

## 输出

```
📅 **运营日报 — [机构] — [日期]**

**预约概况：**
- 今日预约：[N] 例
- 新增预约：[N] 例
- 取消/变更：[N] 例

**病历状态：**
- 待完成：[N] 份
- 即将到期（24h内）：[N] 份 ⚠️
- 逾期：[N] 份 🔴

**提醒：**
- [提醒1]
- [提醒2]
```

## 管理框架

### 归档标准
1. 病历完整性检查
2. 签名和授权验证
3. 分类和编码
4. 归档位置记录

### 保存要求
- 住院病历：[15] 年
- 门诊病历：[15] 年
- 特殊病历：长期保存

### 调取流程
1. 权限验证
2. 调取申请
3. 病历定位
4. 交付记录

### 筛查管理框架
#### USPSTF 筛查体系
- 采用 USPSTF A/B 级推荐作为标准
- 按年龄组和性别匹配筛查项目
- 支持 12+ 种核心筛查类型

#### 筛查状态管理
- `completed`：已完成，系统自动计算下次到期日
- `due`：即将到期（30天内）
- `overdue`：已逾期，需优先处理
- `declined`：患者拒绝，需记录知情同意
- `n/a`：不适用（基于年龄/性别/病史）

#### 筛查频率参考
| 筛查类型 | 推荐频率 |
|---|---|
| 血压 | 每年 |
| 血脂 | 每 5 年 |
| 糖尿病 | 每 3 年 |
| 结肠癌 | 每 10 年 |
| 宫颈癌 | 每 3-5 年 |
| 乳腺癌 | 每年 |
| 肺癌（高危） | 每年 |
| 抑郁症 | 每年 |

### 医生搜索框架
#### NUCC 分类码映射
支持 30+ 专科的 NUCC 分类码自动映射，覆盖心内科、皮肤科、神经内科、骨科、妇产科等核心科室。

#### FHIR 查询支持
- Practitioner 资源查询：获取医生基本信息
- PractitionerRole 资源查询：获取执业角色和机构关联

### 预约管理框架
#### 预约类型
- 初诊：首次就诊
- 复诊：随访复查
- 随访：长期健康管理
- 检查：专项检查安排

#### 时段管理
- 上午时段：08:00-12:00
- 下午时段：14:00-17:30
- 晚间时段：18:00-20:00（部分机构）
- 特殊时段：加号、特需门诊

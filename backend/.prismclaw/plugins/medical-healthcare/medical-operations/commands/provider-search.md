# /provider-search

## 目的

帮助患者或医疗机构快速查找合适的医疗服务提供者（医生、医疗机构），支持按姓名、专科、机构等多维度搜索。

## 执行步骤

### 1. 明确搜索条件

- 确定搜索方式（按姓名 / 按专科 / 按机构）
- 收集必要参数：
  - `name`：医生姓名（模糊匹配）
  - `specialty`：专科名称或 NUCC 分类码
  - `organization`：所属机构名称
  - `location`：地理位置（城市/区域）
  - `insurance_accepted`：接受的保险类型

### 3. 执行搜索

调用 `provider_search` 工具：

- **FHIR Practitioner 查询**：根据条件在 FHIR 服务器中搜索 Practitioner 资源
- **FHIR PractitionerRole 查询**：获取医生的执业角色、机构关联和专科信息
- 支持分页返回，每页最多 20 条结果

### 4. 结果展示

- 格式化展示搜索结果列表
- 显示每个医生的：姓名、职称、专科、机构、位置、联系方式
- 标注是否接受患者保险
- 提供下一步操作建议（预约、转诊等）

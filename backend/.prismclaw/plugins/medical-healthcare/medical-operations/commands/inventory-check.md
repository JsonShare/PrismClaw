# /inventory-check

## 目的

协助医疗机构进行系统化的库存管理，确保药品和耗材的充足供应和合规使用。

## 执行步骤

### 1. 盘点准备
- 确定盘点范围
- 准备盘点表
- 通知相关人员
- 冻结库存变动

### 2. 现场盘点
- 按类别清点
- 核对账面数量
- 检查效期
- 记录差异

### 3. 差异分析
- 分析差异原因
- 标记过期/损坏物品
- 检查安全库存水平
- 生成差异报告

### 4. 采购建议
- 基于消耗率预测需求
- 考虑采购周期
- 生成采购建议
- 提交审批

## 合规方法论

### 一、核心法规框架

**适用法规层级：**
1. **国家法律** — 《个人信息保护法》、《数据安全法》、《基本医疗卫生与健康促进法》
2. **行政法规** — 《医疗机构管理条例》、《医疗纠纷预防和处理条例》
3. **部门规章** — 《医疗机构病历管理规定》、《电子病历应用管理规范》
4. **地方性法规** — 各省市数据保护和医疗合规规定
5. **行业标准** — HL7、ISO 13485 等

### 二、患者数据分类

| 数据类型 | 敏感度 | 保护级别 |
|---|---|---|
| 电子健康档案（EHR） | 极高 | 严格访问控制、加密 |
| 患者身份信息 | 高 | 访问控制、最小必要 |
| 诊断和治疗记录 | 高 | 访问控制、审计追踪 |
| 检验检查结果 | 中 | 访问控制 |
| 匿名化数据 | 低 | 可用于研究 |

### 三、风险分级标准

| 等级 | 含义 | 处置建议 |
|---|---|---|
| 🔴 严重/阻断 | 高风险合规漏洞 | 立即整改、上报管理层 |
| 🟠 重大/高 | 重要合规风险 | 限期整改、记录在案 |
| 🟡 一般/中 | 一般合规问题 | 纳入整改计划 |
| 🟢 提示/低 | 改进建议 | 备查 |

### 四、数据处理原则

1. **最小必要** — 仅收集和处理业务所需的最少数据
2. **目的限制** — 数据仅用于收集时告知的目的
3. **数据质量** — 确保数据准确、完整、最新
4. **安全保护** — 采取适当的技术和组织措施
5. **主体权利** — 保障患者的数据访问、更正、删除等权利
6. **问责制** — 对数据处理活动进行记录和审计

# /data-breach-response

## 目的

提供系统化的数据泄露响应流程，确保符合法规要求并最小化损害。

## 执行步骤

### 1. 泄露评估
- 涉及的数据类型（PHI、PII）
- 涉及的患者人数
- 泄露的可能原因
- 泄露的时间范围

### 2. 风险评估
评估泄露对患者的影响：
- 🔴 极高风险 — 大量敏感数据
- 🟠 高风险 — 少量敏感数据
- 🟡 中风险 — 有限数据
- 🟢 低风险 — 最小影响

### 3. 通知要求
根据适用法规确定通知义务：
- **患者通知** — 时限、方式、内容
- **监管机构通知** — HHS、OCR 等
- **媒体通知** — 如果需要
- **执法机构通知** — 如果涉及刑事行为

### 4. 补救措施
- 遏制泄露
- 评估影响
- 恢复系统
- 预防再次发生

### 5. 文档记录
完整记录事件、响应措施和时间线。

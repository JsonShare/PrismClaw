# Dashboard Template

*由仪表板提供护栏引用。保持仪表板简单一致——价值在于理解速度，而非视觉上的精致。*

## 结构（从上到下）

1. **Title and metadata.** 这是什么、何时生成、涵盖什么内容。一行。
2. **Summary stats.** 重要的计数，颜色编码。例如："40 个发现：🔴 3 个严重 · 🟠 8 个高 · 🟡 15 个中 · 🟢 14 个低——本周 6 个到期。"这是最有价值的行。
3. **The reviewer note.** 来源、范围、标记、依赖前事项。
4. **Chart(s).** 最多一个或两个。选择显示形状的那个：
   - **Severity distribution**（条形图）：按严重程度的计数。
   - **Category breakdown**（饼图或堆叠条形图）：按类型的计数。
   - **Trend**（折线图或排序表）：随时间的变化。
5. **The table.** 可排序、可过滤、按严重性/状态颜色编码。
6. **The decision tree.** 下一步是什么？

## 按展示界面渲染

- **HTML 工件。** 自包含、单个文件、内联 CSS。表格带 `data-sort` 属性。图表用内联 SVG。
- **Excel (可选)。** 对于大量数据，使用 Excel 输出。应用公式注入防护。
- **转义不受信任的输入。** 所有外部值在进入文档之前必须进行 HTML 转义。

## 严重性颜色

- 🔴 严重/危急
- 🟠 高
- 🟡 中
- 🟢 低
- ⚪ 中性/信息

## 保持简洁

- 无动画、无框架、无外部字体。
- 摘要、审阅者注释、图表、表格、决策树。从上到下。
- Markdown 版本很重要——带 Unicode 条形的摘要统计行。

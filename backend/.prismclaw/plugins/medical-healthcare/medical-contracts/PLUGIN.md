# 医疗合同分析插件

## 概述

本插件提供医疗合同分析能力，用于对医疗采购合同、服务协议、设备租赁合同等文档进行问答式分析。

## 模块

| 模块 | 说明 |
|---|---|
| contracts | 跨合同语料库的问答分析，提供带溯源引用的合同解读 |
| documents-reader | 合同文档读取与扫描代理 |

## 工作流程

1. **语料库初始化**：将合同文档上传到本地合同数据库
2. **范围设定**：定义分析范围和问题
3. **批量扫描**：对所有合同进行批量扫描和索引
4. **分类处理**：对扫描结果进行分类和优先级排序
5. **问答生成**：基于分类结果生成带引用的回答

## 安全规范

1. **数据本地化**：所有合同数据存储在本地，不发送到外部网络
2. **版本控制**：合同变更历史完整记录，支持版本对比
3. **引用溯源**：每个结论必须附带合同原文的精确位置引用
4. **审计日志**：所有分析操作记录在案

## 环境要求

- **Node.js**: >= 22（documents MCP 服务器运行时）
- **Bun 或 npm**: 用于安装服务器依赖
- **磁盘空间**: 根据合同语料库大小预留足够空间

## 输出规范

所有合同分析输出必须包含：
- 合同原文精确引用位置
- 分析方法说明
- 置信度评估
- 相关合同版本信息

# /statistics

## 目的

协助研究者选择合适的统计方法，确保分析的正确性和可解释性。

## 决策框架

### 1. 确定数据类型

| 数据类型 | 示例 | 可选方法 |
|---|---|---|
| **连续** | 血压、身高、时间 | t 检验、ANOVA、回归 |
| **分类** | 性别、组别、生死 | 卡方、Fisher 精确检验 |
| **有序** | 疼痛等级、分期 | Mann-Whitney U、Kruskal-Wallis |
| **生存** | 生存时间、无病生存期 | Cox 回归、Log-rank |
| **相关/配对** | 治疗前后比较 | 配对 t 检验、Wilcoxon |

### 2. 选择检验方法

#### 比较两组
- 连续 + 独立 → 独立样本 t 检验（正态）/ Mann-Whitney U（非正态）
- 连续 + 配对 → 配对 t 检验（正态）/ Wilcoxon（非正态）
- 分类 + 独立 → 卡方检验 / Fisher 精确检验
- 生存 → Log-rank 检验 / Cox 回归

#### 比较多组
- 连续 → ANOVA（正态）/ Kruskal-Wallis（非正态）
- 分类 → 卡方检验
- 生存 → Log-rank / Cox 回归

#### 关联分析
- 连续-连续 → Pearson（正态）/ Spearman（非正态）
- 连续-分类 → 点双相关
- 分类-分类 → 卡方 / Phi 系数

### 3. 验证假设
- 正态性检验（Shapiro-Wilk）
- 方差齐性检验（Levene）
- 独立性检验

### 4. 输出结果解释

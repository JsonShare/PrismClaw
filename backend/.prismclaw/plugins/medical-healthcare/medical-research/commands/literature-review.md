# /literature-review

## 目的

协助研究者进行系统的医学文献综述，从检索到综合的全流程支持。

## 执行步骤

### 1. 明确研究问题
使用 PICO 框架构建研究问题：
- **P**opulation（人群）
- **I**ntervention（干预）
- **C**omparison（对照）
- **O**utcome（结局）

### 2. 构建检索策略
- 选择数据库（PubMed、Embase、Cochrane 等）
- 构建检索式（MeSH + 自由词）
- 设定时间范围和语言限制

### 3. 文献筛选
- 应用纳入/排除标准
- 按 PRISMA 流程图记录筛选过程
- 记录排除原因

### 4. 数据提取
- 研究特征（设计、样本量、干预、结局）
- 统计数据（效应量、置信区间、p 值）

### 5. 质量评估
- 使用适合的质量评估工具
- Cochrane RoB / Newcastle-Ottawa 等

### 6. 综合与分析
- 叙述性综合或 Meta 分析
- 异质性评估
- 发表偏倚评估

## 输出格式

```
# 文献综述：[研究主题]

## 研究问题
PICO: [Population] + [Intervention] vs [Comparison] → [Outcome]

## 检索策略
- 数据库：[PubMed, Embase, Cochrane]
- 检索式：[检索式]
- 时间范围：[YYYY-MM 至 YYYY-MM]
- 语言：[英文]

## 筛选结果（PRISMA 流程图）
- 总检索结果：[N] 篇

- 筛选全文：[N] 篇

[研究特征表格]

```

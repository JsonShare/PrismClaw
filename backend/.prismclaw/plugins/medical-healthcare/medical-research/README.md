# 医学研究 Plugin

跨三个核心研究领域的工作流：文献综述、研究设计和统计分析。

**每个输出都是供研究者审阅的草稿——不构成研究结论。**

## 目标用户

| 角色 | 活跃模块 |
|---|---|
| **主要研究者（PI）** | 全部三个 |
| **统计师** | 统计分析 |
| **研究助理** | 文献综述 + 研究设计 |
| **医学生/博士候选人** | 文献综述 + 研究设计 |

## 首次运行

```
/research-cold-start-interview
```

## 命令

| 命令 | 作用 |
|---|---|
| `/research-cold-start-interview` | 模块化冷启动 |
| `/medical-research:literature-review` | 医学文献综述 |
| `/medical-research:study-design` | 研究设计方案 |
| `/medical-research:statistics` | 统计分析方法选择 |

## Skills

| Skill | 模块 | 目的 |
|---|---|---|
| **literature-review-workflow** | 文献综述 | 系统文献检索和综述生成 |
| **clinical-trial-workflow** | 研究设计 | 临床试验设计和方案开发 |

## 安全声明

本插件生成的所有内容均为研究辅助工具。研究结论须经适当的同行评审和统计验证。

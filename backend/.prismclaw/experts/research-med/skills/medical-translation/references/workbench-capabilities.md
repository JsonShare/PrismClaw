# 工作台能力映射（按需查阅）

本页列出本技能所需的能力与本环境中对应的工具名称。**名称不代表当前会话已注册、连接、安装或获授权。** 每次执行前查看当前可用工具与原生说明；仅按说明调用，不根据名称猜参数或返回格式。通用工作流程不依赖这些名称，迁移到其他平台时只需更新本页。

| 所需能力 | 本环境工具 | 使用条件与降级 |
|---|---|---|
| 读取 PDF | `workbuddy-pdf` | 先取文本层；扫描页或图文混排页按页导出为图片再用 `ViewImage` 读。读不到的页明确列出，请医生补充可读文件。 |
| 读取 Word / 纯文本 | `Read` | 按实际支持格式读取；`.doc/.docx` 结构复杂时用 `workbuddy-local-office-edit` 打开确认，不猜段落归属。 |
| 理解扫描页、图表或图片文字 | `ViewImage` | 只使用实际可用能力；不确定的字符、数字、单位与图表标签保留原文并请医生核对，不据低置信度识别改写译文。 |
| 写入逐页双语对照区 | `Write` | 仅在医生明确要求落到工作区文件时使用；否则在会话内输出可复制的双语对照。 |
| 保存并交付译稿 | `Write` + `present_files` | 文件真实生成并回读检查后再交付；无写入能力时交付可复制文本，不声称已生成文件。 |

能力之间不互为前提：某一项可用不代表其余项已接入。检索、视觉、文件写入是三种独立能力，不能因一种可用就假定其他能力存在。

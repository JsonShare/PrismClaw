# 图注来源说明

本文件规定caption_notes；正文解释由模型依据本轮原件撰写，没有预设指标、组名或病例答案。程序只检查引句、题录和声明覆盖，不能证明语义。

## 来源与覆盖

绘图计划必填source_origin=published_data或attached_data。已识别原论文的数据用published_data，即使只做描述图也不能用attached_data回避已读来源。published_data必须有reading_definition，分别覆盖quantity（指标）、group（组别）、observation_unit（每点对应个体）、measurement_material（实际测量材料）；转录原P时还须original_method。可选timepoint、other。

每条只解释一个主题，通常一短句；用用户任务语言写说明，专业缩写与真实名称保留原文，不混用整句英文和中文。每条最多160字、共12条；全部reading_definition正文加group_explanations共不超过650字。group_explanations已自动显示，text不再重复一遍。不要重写程序自动生成的均值±SD、有效n、空白/零值计数、P值转录规则或纵轴标签。观测对象、材料、量纲是三件事，不互相替代。某项未知只说明这一项，不抹去原文已给事实。不添加无关的试剂盒、处理过程或猜测其未报告的细节。测量对象只写原文支持的对象，不把多个不同器官/整体指标合说成同一种材料或制备流程，也不补“不是某种材料”之类排除陈述。未核字段只说明该字段。

本次选择的布局、统计方法、校正范围和分布假设属于分析方案，使用相应plan字段记录，由报告生成本次执行说明；不写成带原文或单元格引证的reading_definition。表头只能支持指标或组名，不能用它给本次方法选择背书。图形选择理由填plan.plot_rationale字符串，报告将它单列为“本次图形选择”，不附来源编号；这里只解释显示选择，不能放入需要原文支持的实验或医学事实。原研究方法另按原文引用。

用户或原始材料明确为相对基线、比值或已归一化尺度时，图中纵轴及图注也保留这一尺度和已知参考基线；单位未注明不等于尺度未知。沿用给定原值，不再次归一化，不将相对量误标为原始绝对指标或擅自加百分号。

## 对应面板与组别身份

源表为FigN.字母形式且source_origin=published_data时，方案增加：
```json
"figure_sources": [{"sheet":"Fig2.b","file":"sources/paper.xml","element_id":"Fig2","panel":"b"}]
```
图号、面板和文件必须来自实际源表及本轮原件。程序读取该面板段落，保存原件和定位。源表的独特科学标识若不在该面板出现，程序在正式图注自动保留并说明名称差异；不要用同篇另一面板或一般模型段替它赋予实验身份，也不要猜笔误。对应group正文只解释该面板真正支持的研究分组，源表标签由图和差异说明原样保留。

group阅读定义增加`group_definitions={"源表组名或其起始组别词":"原文中说明该实验组身份的真实短语"}`。例如某组名带有时间后缀时，可用其不含时间的开头组别词作为键；必须按完整词边界覆盖。值逐字来自该条evidence.quote，正文用本任务语言简短解释其对照、处理或遗传模型含义。另写同键的`group_explanations={"组别词":"本轮依据原文写出的简短生物学解释"}`，程序逐条放入正式图注；不能只在隐藏字段留定义，正文仍只给别名。单纯把短名换成长名仍不是生物学定义。来源身份有冲突的标签由程序说明，不能填入其他模型定义强行覆盖。

逐组核对定义是否确实适用于该组。某处理组的饥饿、给药或诱导条件不能同时作为对照组的定义；源表只能证明其写出的标签，不能替未注明的处理细节背书。原文只说明部分组时，其余组保留源表标签并说明未核实的具体条件，不借用相邻组的原句补齐。

## 每条结构

```json
{
  "text": "本轮原文支持的简短读图定义",
  "source": "原文定位，题录将由程序读取原件替换",
  "purpose": "reading_definition",
  "topic": "quantity",
  "expansions": {"ABC": "actual original long form"},
  "evidence": [{"kind":"article_xml","file":"sources/paper.xml","element_id":"实际图或段落id","quote":"该元素中的真实逐字片段"}]
}
```

expansions在有缩写时使用：键是图面/组名中的缩写，值是原研究或定点核对的权威术语文献中的真实全称；两者同时写进该条text，全称须逐字出现在该条evidence.quote。程序检查明显的全大写或数字字母符号，重复缩写本身不算释义，也不能用“某修饰词+原缩写”充当全称；expansions只解释实际图面标签，不能另填一个相关试剂缩写来代替。原件确未能核实全称时，在相应reading_definition上列`unresolved_expansions=["实际原标签"]`；程序在正式图注披露全称未核实，保留标签与数据；该条text不要再写这个未核标签的释义或相同标签，避免一边给定义一边说未知。不能据相似缩写猜测，也无需为保留原名再问显示偏好。不得为避开已知定义而谎报未核实。不得为通过覆盖检查猜全称；其他必要短缩写同样由模型按原文解释，词法检查不是完整缩写识别器。

article_xml的file相对计划目录，必须为本次真实JATS；element_id来自source_caption.py实际输出。quote只压缩空白，不翻译或改上下标。程序验证唯一原元素、真实引句、原件哈希，自动从front/article-meta读题录并随复现包保存XML。不同事实按实际图注或方法段分别引用，不把全文别处说成目标图定义。

工作簿标签用原格完整文本：
```json
{"kind":"input_cell","sheet":"实际表","cell":"A1","quote":"该格原始全文"}
```
CSV字面用`{"kind":"input_text","quote":"实际输入原文"}`。中文引号声明逐字原文，内容须在该条引句中；不能靠删引号保留假来源。source_audit只供审计，不代替正式阅读定义。

## 科学含义与映射

- 原图轴、图注、方法分别核对。比值不能自行推定是否乘100；年龄、给药后时间、随访时间不能只凭数字差互换。用户确认标签映射不授权添加实验时间线。程序会在正式图注输出本轮映射确认的真实引句及出处；自行写的时间说明不能改成原研究证明了映射。只说明已核目标面板缺直接依据，不从局部搜索泛称全篇或全世界没有某词。
- 论文和源表名称不同时，group定义并列真实名称并分别绑定input_cell/article_xml；不默默统一、不从另一面板借相似鼠系、不凭拼写断定笔误。分组标识词法核对不证明对象相同。正式图注直接说明“源表称…，论文称…，二者名称不同”；分别列出名称却不说明差异不够。没有同一性依据时，不写等同关系或用一方定义替代另一方。
- source_group_mapping.kind=original_source需evidence及真实逐字quote，且引句直接支持对应关系。引句必须包含映射两端实际时间值和单位，程序会拒绝遗漏值；数字同时存在仍不证明映射，年龄与处理后时间必须有直接关系依据。各标签分别存在不证明映射。无直接依据只问必要关系；已有本轮明确确认则kind=user_confirmation并引用真实确认，不能伪造。
- original_method仅描述原研究，不写脚本、本次计算、模拟或复现声明；本次事实由程序生成。原文SEM与本图SD分别说明。某项方法只覆盖一种材料或一类指标时不外推整批。
- 单位未知不使原文明确的动物/供者身份未知。measurement_material核对对应方法，whole organ、分离细胞、组织匀浆和体液不可互换。quantity核指标全称及比值含义。

在analyze.py输出的report.md全文中核对：所有必要定义必须在图注中，来源有实际定位，句子不重复，解释与引句相符。处理时序按方法原文核对：同期开始造模和干预不能写成“造模后给予”；没有直接时序依据时只说明处理组身份，不补先后关系。药物、模型和统计缩写的全称在首次使用前给出，不在组别解释后再重复定义。发现错误改方案并重新生成，不能只加聊天免责声明。

原研究没有提供通用术语全称时，可定点核对权威术语资源或能明确给出该词定义的原始文献；将术语依据与本研究身份/材料依据分开。术语来源只能解释这个词，不能据此补本研究的异构体、鼠系、样本或实验方法。仍无实际依据则如实使用unresolved_expansions，不把未取得写成全世界不存在。

原研究未提供通用缩写全称时，先对该词做一次有界的权威术语或原始文献查证，并实际读取定义。额外术语论文仍用article_xml真实段落绑定；先核研究语境与缩写通用含义，不能把数据库返回的某个异构体自动当作原研究检测对象。原研究未交代异构体时明确保留该边界。确实未取得可靠定义才用unresolved_expansions；这能如实交付但不代表独立图注已完整。

本篇缺少术语释义时可运行 `scripts/lookup_term.py --term <实际缩写> --context <必要语境词> --output-dir <工作区>/term-sources`。最多取3篇公开全文、每篇8 MiB，60秒预算内不重试；返回真实题录、XML哈希和候选原段落。用实际返回的file/element_id/quote绑定article_xml证据，核清通用含义再引用。它不会自动判断含义，更不能从额外文献补本研究的异构体或实验身份；没有候选段落不代表世界上没有定义。

本轮输入冲突、实际用户澄清及推断未完成范围属于当前核对状态，写入plan.analysis_notes字符串列表，由报告独立分节列点，不挂原文来源编号。这里只说明当前状态及真实依据，不能放入外部医学事实；不把只含组名的表头作为“尚未核实”结论的引证。原文对指标、模型及方法的定义继续使用reading_definition和真实原件。

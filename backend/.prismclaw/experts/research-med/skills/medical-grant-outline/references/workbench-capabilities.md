# 工作台能力映射（按需查阅）

本页列出本技能所需的能力与本环境中对应的工具名称。**名称不代表当前会话已注册、连接、安装或获授权。** 每次执行前查看当前可用工具与原生说明；仅按说明调用，不根据名称猜参数或返回格式。通用工作流程不依赖这些名称，迁移到其他平台时只需更新本页。

| 所需能力 | 本环境工具 | 使用条件与降级 |
|---|---|---|
| 读取申报通知、指南、表格与附件 | `workbuddy-pdf` | 按页读取；扫描页只在实际读取成功时纳入依据，读不到就列缺口，不据标题猜章节要求。 |
| 读取已提供的图片或截图 | `ViewImage` | 只用真实图片路径。无法确认的编号、日期、金额与栏目结构保留缺口，不补猜。 |
| 核实研究背景与医学主张 | `knowledge_search` | 医学证据的优先入口。围绕具体主张、对象与时间检索，检查返回条目是否真的支持该句；摘要不等于已读全文。 |
| 查官方项目通知与申报口径 | `WebSearch` 优先，必要时 `WebFetch` | 项目通知以发布机构官方渠道为准；同一通知的不同转载版本冲突时以官方原文为据，并标注版本与年度。 |
| 撰写框架与正文 | `Write` | 默认先在会话内交付可复制框架；医生要求落文件时才写入工作区。预算数字、行政事实、申报截止日一律留占位，不代编。 |
| 展示或下载已有文件 | `present_files` | 文件真实生成并回读检查后才调用；它不创建或转换文件。按实际返回状态说明。 |

能力之间不互为前提：某一项可用不代表其余项已接入。检索、视觉、文件写入是三种独立能力，不能因一种可用就假定其他能力存在。

# 工作簿分组核对

## 建立映射

1. 用 openpyxl 读取指定工作表的原始单元格、合并范围和表头坐标。使用非只读模式读取合并信息；公式计算值与公式原文分别读取，缓存为空时停止使用该公式值。
2. 列出每列在指定观测行内的非空数量，标出整个观测区内为空的分隔列。空白单元格保持缺失；不将单个缺失值当成分组边界。
3. 用已读的图注、数据字典或用户明确说明给连续数据块命名。多个解释都成立时，保留歧义并停止该部分。样本量一致仅为核对条件，仍需分组语义依据。
4. 保存映射文件：原始文件 SHA-256、工作表、数据区域、各组列范围、各行时间点、原始值与目标值的转换关系、独立来源的预期样本量、来源文件与位置。
5. 用该映射抽取带单元格坐标的观测表。逐观测检查范围覆盖、重复、缺失、组名、时点、数值和转换；计算得到的 n 必须与独立来源一致。
6. 绘图只读取已通过检查的观测表。完成绘图后，再对交付的观测清单运行同一验证。保留验证回执；失败时不登记图件交付。

## 合并与分隔的边界

合并范围是工作簿结构事实。它可以说明表头覆盖哪些列，不能单独证明受试者身份、配对关系或统计设计。未合并的标签可能被作者放在组内任意一列，不能将标签所在列直接当作组起点。

遇到标签位于连续观测块内部的情况，应保留该位置与数据块起点不同这一事实。组别范围需要原始数据说明或图注支持；如果使用另一种范围解释会改变来源记载的样本量，必须先解决矛盾。

## 本候选的可执行检查

`scripts/validate_mapping.py` 使用 openpyxl、csv 和 JSON。映射明确限定实际数据区域，校验程序不会自动猜测列语义。映射中的来源哈希和位置用于追溯；来源语义仍须在建立映射时核对。程序对原始数据和错误绘图 CSV 都直接读取，不执行绘图或模型调用。

实际映射由当前任务的附件、原始说明和分析目标建立。该程序验证数据映射，不验证因果关系、统计设计或图面布局。回归用的真实案例方案保存在部署包外，不向运行中的模型提供答案映射。

## 方案与命令

模型从实际附件建立 JSON 方案，填写 `workbook`、`sha256`、`sheet`、`region`、`scale` 和 `semantic_evidence`。`semantic_evidence` 包含实际读取的 `local_source` 路径、`location` 位置和 `statement` 内容；源文件可以是原文数据说明，或包含完整设计依据的当前题面原文。

`rows` 中每项包含实际 `row` 与该行的 `position`（时间或其他位置标识）。`groups` 中每项包含 `name`、`first_column`、`last_column`、`header_cell`、实际 `header_text`、按 rows 顺序填写的 `expected_n`。预期 n 来自独立来源；组名不同于原始标签时用 header_text 保留原文，不能改动原工作簿。

程序读取实际合并范围。表头落在合并区域内时，读取左上角原文，并检查映射列是否位于该合并范围内。实际观测分布、分隔列和原文可能与工作簿的合并范围冲突，不能仅依据合并范围强制归组。

映射跨出合并表头时，默认停止。只有已经读取的原始图注或数据说明足以解决冲突，才在该组的 `merged_header_resolution` 中保存 `source` 文件、`location` 位置和 `reason` 依据。程序记录冲突和来源哈希，并继续检查独立来源的样本量及逐单元格观测；程序不能代替来源语义核验。未解决的冲突必须保留未决状态，不能用一句“已确认”放行。未合并的表头使用真实单元格文字，其位置不决定分组起点。

设 `P` 为指定解释器绝对路径、`S` 为本次 Skill 实际资源目录、`W` 为本题工作目录：

```bash
P S/scripts/validate_mapping.py --root W --mapping W/mapping.json --output W/mapping-check.json --emit-observations W/observations.csv
P S/scripts/validate_mapping.py --root W --mapping W/mapping.json --observations W/plotted-observations.csv --output W/plot-data-check.json
```

输出或待核验的 CSV 字段为 `source_cell,group,position,source_value,plot_value`。`scale` 仅执行方案明确的乘法转换；不需要换算时使用 1。原始值与转换后的值同时保存。映射检查通过后才能绘图，交付前再检查实际绘图清单。

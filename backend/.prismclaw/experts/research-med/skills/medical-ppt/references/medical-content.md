# 生成前的医学内容核查

核查对象是用户任务、实际原资料和准备上页的文字、数据、图表标签及所需备注，不只看大纲或自己的摘要。纯排版、读取和格式转换保留已确认语义，不自动扩大成重新循证。

## 来源与事实

- 关键医学结论应能定位到真实依据。用户材料、已确认的科室数据和实际读到的文献按各自用途使用；内部工作汇报不强制外部文献检索。新增诊疗建议、剂量、时间窗或指南推荐时核对相应可靠来源、版本及适用范围。只有摘要或部分原文时，结论限于实际可核实内容；不编造题录、DOI或检索结果。
- 分清原文上报、派生计算、推断、拟议措施与实际结果。缺少记录不等于工作没开展；计划不等于已实施，模拟教学数据不冒充真实病例。患者身份信息只保留任务所需，分享材料避免携带无关可识别信息。
- 在生成前集中完成关键数字、研究身份和适用条件核对。核对引用研究的题名/DOI、研究类型、人群、比较方案、终点及统计时点，避免认错研究或把跨研究结果写成直接优劣比较；不把检索命中或来源注册当成已核实证据。已核信息在制作中复用，不等交付后补核，不另加审核轮次。
- 在每页的来源记录或必需备注中保留检索实际返回的来源ID，以及文件或URL及页码、表号、段落等实际定位。用户材料使用文件定位即可，不强制外部检索；不虚构来源ID，也不为此另建台账。对应正文、图表标签和备注写清必要条件；字段不是证明，仍须对照原文。不另建逐句事实ID、核查台账或重复内容包。少量跨页复用或派生数字在内容稿里标明出处页，便于改动时定位相关页，不要求每页都建绑定表。

## 优先核对会改变理解或行动的内容

| 核查点 | 判断重点 |
|---|---|
| 医学条件 | 人群、疾病阶段、前提、禁忌、否定、推荐强度与紧急度是否被压缩丢失；“可考虑”不能改成“必须” |
| 数字口径 | 单位、分母、统计期间、比较对象、去重与总数/子集关系是否有原文依据；即使每月数值都能拟合某公式，也不能据此确立未知定义或改写原单位。未知时标“原文口径未说明”，不据此做排名或趋势归因 |
| 目标与安全阈值 | 不良事件上限是风险控制边界，不是可使用的额度。可写“截至某月发生X例；年度控制目标≤Y例，继续预防”，不能写“剩余额度/还可发生/用掉一半”。阶段数据不扩大为全年达标 |
| 观察与原因 | 构成比、阶段分布或静态病例分期只描述观察；不能单凭它们断言识别不足、管理失效、病情进展或干预有效。原文未给出因果证据时不补成既定问题；有合理依据的假设可标“待核查方向”，无依据则省略 |
| 研究结局状态 | 按具体终点分别区分已报告结果、未报告结果及长期不确定性；不能把一项未报告结局扩大成整类结局未报告，也不能把长期未知写成当前没有数据 |
| 研究与行动状态 | 自己的研究、文献结果、教学示例、分析计划分别表述；未做的研究或检测不补成已有成果 |
| 一致性 | 正文、图表、备注和总结使用相同数字与含义；共享事实变化时定位所有相关页 |
| 原图与示意 | 临床/论文原图保留必要图例、轴标、单位、比较组及来源；示意不冒充真实影像、照片或研究数据 |

关键计算、排序和变化方向优先用可复算的方式重新核一遍，已确认的普通加总无需反复核算。原文疑似有错时保留原值与具体疑点，不靠拟合出的单位、分母或分类替换定义。

## 核查无进展时如何继续

围绕疑点定位实际原文及必要的补充依据；没有新线索、不影响主结论时停止重复搜索或重读，选择以下处理，不再强求唯一解释：

- 单位、分母或定义不明：保留原文值并标“口径待确认”，不据此换单位、做跨组比较或推导趋势。
- 原因或作用机制未获证实：只保留有依据的观察；确有合理依据的解释可标为“可能因素／待核查方向”，没有依据则省略，不把猜测加个“可能”就当事实。
- 非必要细节查不清：省略该细节，或在备注说明未确认。影响观众理解的限制留在相关正文，不全部藏进备注。
- 核心数据冲突、诊疗剂量/禁忌/适用条件不明确：不能用含糊措辞放行；明确差异或缺口，暂缓对应结论，完成其余独立内容。仅在确需用户信息才能继续时集中询问。

收窄的是结论范围，不是准确性。已有可靠证据能回答的问题直接准确表达；不要把已知错误改成模糊但仍误导的说法。

## 适合演示的表达

每页突出一个主要信息和直接依据，详细核算、长表及完整出处可放备注，用户要求完整展示的内容仍保留。会改变结论或临床行动的条件在相关正文、图注或表头简短可见，不全部藏进备注。普通待核说明用中性层级，不做满页警告条。

措辞可以等义概括，不要求逐字复制。专业同行无需解释所有常识；跨专业教学或患者教育解释影响理解和行动的术语。患者稿以可理解的表达为主，必要的求助信号、禁忌和适用条件不能为美观省略。病例、教学示例或讨论问题可以保留不确定性，不为得到唯一答案补造事实。

## 处理核查意见与返修

一次集中找出实质问题。每个需要修改的问题说明原句、依据或缺口、影响的含义及相关页面；意见本身也要核对原文，不能因被标成错误就直接采用新结论。无依据的偏好建议可以不采纳，已有措辞准确且可理解时不反复改写。

先修内容，再生成演示文稿。自动检查发现的定位问题合并进本次核查，但自动检查通过不能代替原文语义核对。命中提示不等于错误：带否定、必要临床前提或准确引文时保留其含义，不为消提示删掉限制。上述判断同时覆盖标题、结论句、图表标签和备注，不只核对数据表。局部内容变化核对受影响整页与必要上下文，并同步共享该事实的其他页；纯排版变化不重做医学核查。未变内容复用已完成核对，没有新实质问题即可结束，不设置额外最终审核或固定重审次数。

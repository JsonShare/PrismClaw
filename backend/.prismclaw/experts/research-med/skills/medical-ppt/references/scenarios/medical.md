# 通用医疗场景模板

> 所有医学任务的默认设计模板，采用学术研究报告的清晰、规整与克制风格。适用于临床教学、MDT、文献与指南、科研、科室汇报、护理质控、患者教育及团队介绍。内容按真实任务组织，不要求套用研究报告章节。
---

## 一、默认视觉规范

### 1.1 用户模板优先

已有机构模板、品牌色或参考稿时沿用；只给机构名称并不要求再询问或搜索一轮视觉系统。未提供Logo不补造，未指定的视觉要素采用下列默认值，普通设计选择自主决定。

### 1.2 默认配色

| 角色 | 颜色 | 用途 |
|---|---|---|
| 主色 | `#245B83` 沉稳医学蓝 | 编号、章节标识与主要图表系列；标题颜色按版面选择 |
| 辅色 | `#6C8FAE` 灰蓝、`#EAF1F7` 浅蓝 | 线框、次要图表系列、信息横幅和局部底纹 |
| 风险强调 | `#B64545` 警示红 | 有依据的风险、异常及需采取行动的提醒 |
| 普通重点 | 主色加粗或 `#EAF1F7` 浅蓝底 | 关键数据与结论；风险红保留给风险和异常 |
| 文字 | `#172B3A` 深墨、`#526777` 灰蓝 | 标题与正文、次级说明及引用；次要层级通过字号与字重区分 |
| 页面背景 | `#FFFFFF` 白 | 正文页面；分区底用 `#EAF1F7` |
| 封面底色 | `#DCE8F1` 浅蓝灰 | 大标题与留白建立专业感；可选贴边浅色分区或简洁主蓝色线条、窄边条，沿用正文主题。装饰与标题或页边对齐，不强制加实色色块，不嵌套悬浮深色矩形；构图完整即停止添加装饰 |
| 线框 | `#D6DCE5`、`#E5E7EB` | 表格分隔、卡片描边和页脚线 |

全稿沿用一套颜色角色，蓝色用于结构与重点，正文区保持清爽；风险红只作少量强调。主色、辅助色和背景色不互相混用。封面采用同色系的柔和有色背景，具体要求见[技能入口](../../SKILL.md)；正文可以白底或浅底。用户模板优先。辅色 `#6C8FAE` 用于线条、图表和标记，不作白底小字；小字、单位、引用用 `#526777`，表格文字按实际底色保证可读性。颜色面积只服务于设计判断，不增加比例验收或返修轮次。

### 1.3 字体

- **中文主标题**：封面和页面主标题用 **思源宋体 Bold（Source Han Serif SC）**。简短大标题体现学术感；标题较长或空间紧凑时可用思源黑体 Bold，整稿同类标题保持一致。
- **主要正文**：用 **思源黑体 Regular（Source Han Sans SC）**；小标题、表头用思源黑体 Bold，图表标签与注释用思源黑体 Regular。
- **英文与数字**：统一 **Arial**，标题随段落用 Bold，正文用 Regular；数字统一小数位与对齐，单位跟随所在文字样式，不另用装饰字体。
- 字体以宿主实际可用项为准。宋体依次回退到 Noto Serif CJK SC、宋体类可用字体，黑体依次回退到 Noto Sans CJK SC、苹方或微软雅黑；Arial 缺失时用可用同类无衬线。一次确认后全稿复用同一套标题、正文和英文字体，不临时寻找字体工具。包内不附带字体文件；回退后按实际字体判断排版，不声称字体已嵌入。

### 1.4 字号阶梯（画布 1280×720）

| 层级                           | 字号              | 字重               | 用途                                                              |
| ------------------------------ | ----------------- | ------------------ | ----------------------------------------------------------------- |
| 封面中文主标                   | 54-72px           | Bold               | 封面唯一主标                                                      |
| 封面英文长 title               | 40-56px           | Bold（Arial） | 封面副标式英文长标题                                              |
| 章节扉页大数字                 | 120-280px         | Bold               | 章节扉页 01 / 02 / 03 等                                          |
| **页主标题** | **32-40px** | Bold               | 每页主标题，底色与字色自主选择                                                |
| 副标题 / 章节英文名            | 18-22px           | Regular / 600      | 章节标识或副标题                                            |
| 卡内小标题                     | 22-28px           | Bold / 600         | 多卡页的每张卡标题                                                |
| **正文**                 | **20-24px，最低 20px** | Regular            | 卡内正文、段落；复杂内容同样遵守，不靠缩字塞内容 |
| **KPI 重点数字**           | **48-72px** | Bold               | 仅强调少量真正关键的数据（三联数、单核心数据），不逐页或对普通数值反复使用 |
| 表格                           | 16-20px           | Regular / Bold     | 表头 Bold，表体 Regular                                           |
| 图表标签 / 轴                  | 14-16px           | Regular            | 图表内文字                                                        |
| 注释 / 引用 / 页脚             | 14-16px           | Regular            | 来源、脚注、页码                                                  |

**几个硬下限**：正文**不低于 20px**，卡内小标题**不低于 22px**，页面主标题**不低于 32px**。不要把承载主要结论、解释或必要条件的正文当成小字注释；14px 只适用于注释、引用与图表标签，不是正文字号。文字与实际背景保持足够对比；标题底色、字色和是否使用色条均不预设。

## 二、内容组织与页面参考

### 2.1 行文风格

- **平实优先**：医学表达优先准确、简洁，少用形容词和修辞。用准确的术语、完整的句子、清楚的逻辑。避免"重大突破""深远影响""开创性地"这类词。
- **论断要有依据**：每一个观点后面跟着文献、数据或推导。没有依据的判断就是猜测，要标明是推测。
- **诚实报告局限**：研究有什么不足、数据有什么限制、结论适用什么范围——写出来比藏着更专业。
- **按受众表达**：面向同行保留必要专业术语，不重复解释常识；教学或患教按受众解释必要概念、适用条件与行动要点，不堆砌术语。

### 2.2 硬禁止

- **编造引用和数据**：参考文献必须真实存在；数据必须来自真实来源或自己的实验/调研。公式必须可追溯到教材或论文。**这是学术报告最不能碰的红线。**
- **AI 味表达**：卖点式标题（"重大突破""开创性"）、对称罗列（三大创新/五大贡献）、万能句式、emoji 与感叹号。
- **无目的的空散**：围绕论点与证据安排留白，不为填满页面扩写内容。
- **卡片感容器**：避免"大圆角 + 饱和底色 + 明显阴影"的浮起卡片。

### 2.3 按任务选择内容

教学、病例、质控、患教等任务的内容顺序按具体任务自行组织，沿用本文件的配色、字体与版式。仅实际研究报告可按需采用 **IMRaD**（背景、方法、结果、讨论）；其他任务不补造研究问题、实验、导师或研究结果。

PPT呈现任务所需的结论与关键证据，详细推导、原始数据和长文献可按需放备注或附录，不额外增加页数。以下页面是可选参考，不是每份稿都需要的完整清单；对应布局见2.4。

| 页面                               | 内容要讲什么                                                                                                                                   |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. 封面页**                | 任务主题、必要副标题、实际署名及角色、单位与日期；英文题名或导师仅在任务提供且确有需要时使用。是否加封面遵循技能入口，不堆细粒度数据。                               |
| **2. 目录页**                | 3-6 个章节编号 + 中文章节名；可配英文名。                                                                                                      |
| **3. 研究背景与问题页**      | 为什么研究这个、现有的痛点或争议、本研究要回答的核心问题。核心问题最好能被质疑、能被验证，不写成中性陈述。                                     |
| **4. 文献综述页**            | 已有研究做到了哪一步、分成几条脉络、各自的代表作与局限、共同的空白在哪。**结尾一句**：现有研究集中在 X、对 Y 关注不足，本研究从 Y 切入。 |
| **5. 研究问题与目标页**      | 把第 3 页的"大问题"拆成 2-3 个可验证的子问题（Q1/Q2/Q3）；对应 2-3 个研究目标。目标要具体可考核，不写"提升效果""深入研究"这类虚词。            |
| **6. 技术路线 / 研究方法页** | 整体技术路线分几个阶段、每个阶段做什么、阶段间怎么衔接；关键方法选型与理由（为什么用这个方法不用别的）。理工科可附关键公式或样本量表。         |
| **7. 研究结果页**            | 发现了什么——**客观呈现，不做解读**。关键数据、关键图表、关键对比，附图下的客观结果说明。                                               |
| **8. 讨论页**                | 结果意味着什么、与已有研究一致还是冲突、为什么会这样；最后回扣第 3 页的研究问题。                                                              |
| **9. 结论与展望页**          | 结论 3-5 条（对应研究问题）、**研究局限**（诚实列出，不藏起来）、后续方向。                                                              |
| **10. 参考文献页**           | 文献列表，每条前面带**方括号序号**（`[1]` `[2]` `[3]`...），序号与正文中的引用一一对应。字号可小（14-16px），可读即可。**不编造文献**——这是红线。详细格式见 2.4.6。                                                                    |

### 2.4 可参考的布局与视觉骨架

默认采用规整、克制、证据清楚的视觉方向；对齐、主次和可读性保持稳定。按以下页型选择或组合，不要求每页都使用同一种顶条或对称布局。

#### 2.4.1 标题与页脚的位置参考

- **页面标题区域**：主标题 32-40px Bold；按内容选择位置、留白及是否添加章节标识。标题背景、字色和色条由设计自主决定，不指定固定组合。
- **底部页脚**：高约 20px，灰色 14px。左侧放任务主题或汇报名称；右侧放页码（如 `04 / 18`）。
- 正文同类页沿用协调的标题与页脚位置；封面和过渡页可采用不同构图，不必添加相同标题区域。

#### 2.4.2 可参考的内容布局

下面保留学术设计常用的页面布局，医学任务可按信息关系挑选或组合。保持视觉对齐和清晰归属，允许有目的的非对称构图。

| 布局                                  | 适用页面                           | 结构描述                                                                                                                                                                                                  |
| ------------------------------------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **信息横幅 + 主体**             | 几乎所有内容页                     | 在标题与主体之间按需设置一条信息横幅，里面放一个 kicker（如「关键观察」「综述问题」「路线设计」「研究目标」）+ 一句话问题或论断。横幅下方是本页主体内容。这是学术 PPT 最常用的开场器。 |
| **三栏并列卡片**                | 文献综述（三条脉络）、研究目标三条 | 三张等宽等高卡片横向排列，白底 + 灰色描边（**不要底色填充**）。每张卡顶部有编号（Ⅰ/Ⅱ/Ⅲ 或 ①②③）+ 小标题 + 时间或领域标签；中段是 3-5 条要点；底部放代表文献或关键数据。                       |
| **左右两区（6:4 或 5:5）**      | 研究问题 vs 研究目标、方法 vs 结果 | 左右两个大块，每块内部可以再分 2-3 个小区。两区可以用竖线或留白分隔；两区高度严格对齐。                                                                                                                   |
| **阶段流程链**                  | 技术路线、研究方法                 | 顶部一行放 3-6 个阶段卡片（白底描边 + 小标题 + 要点），中间用箭头或横线连接；下方放一条**阶段输出条**（浅蓝底），再下方用虚线表示滚动迭代或反馈闭环。                                           |
| **2×2 / 2×3 关键词矩阵**      | 文献脉络、技术维度、研究创新点     | 2 行 2 列或 2 行 3 列的方格，每格一个编号 + 关键词 + 一句解释。所有格子等宽等高。                                                                                                                         |
| **大图配文（图 50% / 文 50%）** | 研究背景、实验装置、结果示例       | 左半图、右半文；或上图下文。文字区包含小标题 + 2-3 行说明 + 底部结论条。                                                                                                                                  |
| **KPI 三联数**                  | 少量核心研究结果、关键数据总结             | 一行三个重点数字（48-72px Bold 主蓝），每个数字下方跟一行说明（20-24px）。仅在核心数据确有并列比较价值时选用，不作为每页默认布局。                                                                                               |
| **文献对比表**                  | 文献综述、结果对比                 | 表格列固定（研究 / 方法 / 结论 / 局限 或 已有研究 / 本研究 / 是否一致）。表格**透明底、无行填充色**，重点行用**加粗**或**上下边框线**标记。                                                                 |
| **底部结论条**                  | 几乎所有正文页                     | 页面最下方一条浅底横条（或细边框条），放一句话结论或整页要点——**让读者带着一句话走**。                                                                              |

#### 2.4.3 组件与装饰（克制使用）

- **编号标签**：Ⅰ/Ⅱ/Ⅲ 或 ①②③ 或 Q1/Q2/Q3——同一组用同一种，不混用。
- **深蓝实色卡**：全篇总共不超过 3 张（通常用于信息横幅或关键结论），多卡并列页**禁用**深蓝实色，不然视觉过重。
- **图表**：让主要图表有足够阅读空间，优先现有Python入口支持的原生折线、柱状等图表；时间轴和流程用原生形状与文字组合，复杂图像沿用素材流程。保留原图的组别、单位、图例与来源。
- **公式与代码**（按任务需要）：公式独立成块并保留变量、单位和必要编号；伪代码只放关键片段。使用现有Python对象或可读素材，不假定存在额外SDK接口。
- **禁用**：3D 字、艺术字、空心字、烟花、印章、金装饰、人物大头照、营销插画、彩虹渐变。

#### 2.4.4 密度与留白

- 内容页主体区铺满宽度（≈1200px），**不要让元素挤在中央 60% 里**。
- 卡片高度贴合内容，留白服务于主次；不按填充率返工。
- 并列内容选择稳定的对齐基准，整体规整；不为数像素差异重开返修。
- 文字与实际背景保持足够对比；不固定标题底色和字色。

#### 2.4.5 关键信息的着色强调

医学演示的**重点数据、关键论点、核心发现**必须通过**视觉强调**让听众一眼抓到——不要指望平铺直叙的正文能被看进去。强调手段按优先级：

1. **适度放大**：只有真正支撑本页结论的关键数字才单独做 **KPI 重点数字**（48-72px Bold）；普通数值保留在正文、表格或图表中，不为了装饰频繁放大
2. **颜色高亮**：关键词或关键数据用**主蓝** `#245B83` 加粗；有依据的风险或异常才用**风险红** `#B64545`；一般名词和过渡性文字保持正文色 `#172B3A`
3. **高亮底条**：核心论点或关键结论用**浅蓝底条** `#EAF1F7` 打底，字保持正文色——这是最接近真实学术 PPT 的"马克笔画线"效果

**什么内容必须被强调**：

- **样本量 / 实验规模**（如 `N = 5469`、`纳入 12 家医院`）
- **核心指标数值**（如 `准确率 92.3%`、`p < 0.001`、`相关系数 0.78`）
- **关键发现句**（如"本研究首次发现 X 与 Y 存在显著负相关"）
- **本研究 vs 已有研究的差异点**（文献对比表里的"本研究"行）
- **研究局限的边界条件**（避免被误读）

**几条纪律**：

- **强调是稀缺资源**。一页里红色或高亮底条总共不超过 **2-3 处**，多了就等于没有强调
- **不用整行底色填充表格**——重点行用加粗 + 上下边框线标记，表格本体保持透明（见 2.4.3）
- **不要只靠加粗**——学术 PPT 里加粗太常见，光靠加粗抓不住注意力。颜色、字号、底条至少配合其一

#### 2.4.6 参考文献格式

参考文献页**不是装饰性收尾**——是学术专业度的直接体现。格式必须规范。

**序号规则**：

- 每条文献前加方括号序号 `[1]` `[2]` `[3]`...，数字右对齐或左对齐都可以，整页统一
- 序号要与**正文中的引用一一对应**。正文里引用某文献时写成"...已有研究表明 [3]"或"Smith et al. (2020) 的方法 [5] 表明..."
- 文献太多时按**正文首次出现顺序**编号（IEEE 风格）；或按**作者姓氏字母 / 发表年份**排序（APA / GB/T 7714 风格）——两种选一种，不混用

**引用格式**：遵从用户或机构要求，未指定时采用全文一致的简短编号或作者—年份格式。只填写已核实的作者、题名、期刊和年份等信息，详细定位可放对应备注；不为套格式补造题录。正文编号与实际来源对应，信息密集时保留可读的短引用，完整题录按任务需要放文末或备注，不为补引用页擅自突破页数要求。

## 三、制作时按需检查

内容项纳入生成前文本核查，视觉项按实际渲染结果核对疑点页，不额外增加全稿审阅轮次。

**内容层面**：任务目标与关键条件是否清楚？来源是否真实可查？事实、表格和结论是否对应？观察与推断是否区分？教学或患教的行动建议是否符合对象？研究稿的方法与结果是否对应、局限是否诚实？并入已有医学内容核查，不再逐项另审。

**视觉层面**：组织风格（色、Logo、字体）是否沿用一致？字体字号阶梯是否稳定？图表标签和引用来源是否可读？表格底色与当前主题是否协调、内容是否可读？

**对齐与密度**：区块左边缘同一竖线、并列区块顶/底齐平、同级间距协调、留白有目的。返修范围与停止条件见[技能入口](../../SKILL.md)的停止条件一节。

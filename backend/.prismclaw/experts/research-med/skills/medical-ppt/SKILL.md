# 医学演示文稿

发起医生是唯一流程用户和最终确认人。脚本执行成功、渲染通过、文件生成都不等于医学批准；交付为待医生确认的草稿。

## 分工边界

本技能管**内容与视觉规范**，不管实现。生成路径统一走 `已安装的 pptx 技能或 bash 编程生成`：

| 任务 | 承接方 |
|---|---|
| 从材料/大纲/数据新建 PPT | `已安装的 pptx 技能或 bash 编程生成`（其「创建」路径） |
| 基于机构模板或已有 PPTX 生成 | `已安装的 pptx 技能或 bash 编程生成`（其「模板复用」路径） |
| 改标题、改某页、增删页 | `已安装的 pptx 技能或 bash 编程生成`（其「编辑」路径） |
| 读已有 PPT 并回答内容问题 | `已安装的 pptx 技能或 bash 编程生成`（其「理解」路径） |
| 医学内容核查（上页文字、数字、研究身份、来源、适用条件） | 本技能，见 `references/medical-content.md` |
| 医疗场景视觉规范（配色、字体、字号阶梯、内容组织） | 本技能，见 `references/scenarios/medical.md` |
| 研究数据图 | `medical-scientific-figures`（数据计算仍走 `biomedical-statistics`） |
| 面向患者的通俗话术与宣教口径 | `medical-patient-education` |

不自行写脚本生成 pptx、不自行拼 XML、不调用外部 Office 组件或第三方渲染器；`已安装的 pptx 技能或 bash 编程生成` 用哪套页面描述与构建工具，按其说明执行，本技能不覆盖、不臆测其参数。

## 流程

1. **定场景与体量**：确认受众、用途、页数预期与是否要封面。七类常用场景（临床教学、病例讨论 MDT、文献与指南分享、科研开题与答辩、科室与护理质控 PDCA、患者与家属教育、团队介绍）只提供默认内容组织思路，可合并、重排、跨场景组合，不强制固定章节。
2. **定视觉规范**：默认取 `references/scenarios/medical.md`；已有机构模板、品牌色或参考稿时以用户件为准，未提供的 Logo 不补造。全稿只用一套主题色含义、字体家族、标题/正文/注释层级与同类页标题页脚位置；页面可按信息关系改构图与密度，但不逐页换风格。
3. **集中做内容核查**：按 `references/medical-content.md` 对着实际原资料核对准备上页的文字、关键数字、图表标签、研究身份（题名/DOI/研究类型/人群/对照/终点/统计时点）、适用条件与所需备注。核查在生成之前一次做完，制作与返修阶段复用已核内容，不留到交付后补核。
4. **出逐页内容稿**：每页一个主要信息 + 直接依据；详细核算、长表与完整题录放备注。内容稿是本技能的交付前产物，不要求与 `已安装的 pptx 技能或 bash 编程生成` 的页面文件同名或同结构，交由其按自身格式落成页面。
5. **交 `已安装的 pptx 技能或 bash 编程生成` 生成**：把逐页内容稿与第 2 步的视觉规范一起交付，说明受众、页数、封面要求与必须保持原样的关键数字。
6. **疑点页返修**：只对影响理解的页面返修（遮挡、裁切、层级失衡、图表不可读）。先改内容稿再重建，不为同一批问题反复多轮。
7. **交付**：给成品文件与核查记录（保留了什么疑点、哪些结论已收窄范围）。

## 停止条件

- 内容核查：围绕疑点查不到新线索、且不影响主结论时停止重复检索，按 `references/medical-content.md` 的「核查无进展」处理——保留原值并标口径待确认、把无依据的解释降级为待核查方向或省略。核心禁忌、剂量、适用条件查不清时不放行，明确缺口、暂缓该结论、完成其余独立内容。
- 视觉返修：主要信息可读、无误导、无明显遮挡/裁切/层级失衡即停，不追求比例验收。

## 输出规范

- 成品演示文稿（可编辑）
- 逐页内容稿与来源记录
- 待确认清单：口径不明、原文疑似有错、需医生裁定的判断

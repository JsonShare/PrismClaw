# 工作台能力映射（按需查阅）

本页列出本技能所需的能力与本环境中对应的工具名称。**名称不代表当前会话已注册、连接、安装或获授权。** 每次执行前查看当前可用工具与原生说明；仅按说明调用，不根据名称猜参数或返回格式。通用工作流程不依赖这些名称，迁移到其他平台时只需更新本页。

| 所需能力 | 本环境工具 | 使用条件与降级 |
|---|---|---|
| 读取稿件、审稿意见、图表说明 | `Read`；`.docx` 用 `workbuddy-local-office-edit` | 读取不完整时标明未检查的章节；不把模板栏目当成该稿已有内容。 |
| 读取 PDF（参考文献、期刊要求） | `workbuddy-pdf` | 按页读取；只取得题录或摘要时不视为已读全文。 |
| 读取数据表 | `workbuddy-sheetagent`，或 `Read` 直读 CSV | 核对变量名、单位与分母后再引用数字；口径不明先问，不按列位置推断。 |
| 核对医学背景与研究来源 | `knowledge_search` | 关键事实回到可读原文；检索摘要只用于定位。 |
| 补查公开文献 | `WebSearch`，需要正文时 `WebFetch` | 长网页返回落盘路径时，用 `Read` 读相关章节而非整篇；仍有缺口的结论标为未核。 |
| 交付稿件与问题清单 | `Write` + `present_files` | 仅在实际可用时使用；交付不代表已向期刊投稿。 |

能力之间不互为前提：某一项可用不代表其余项已接入。检索、视觉、文件写入是三种独立能力，不能因一种可用就假定其他能力存在。

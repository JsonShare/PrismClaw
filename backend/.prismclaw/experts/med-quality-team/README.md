# 医疗质控专家团

面向医疗质量与合规的多角色专家团，覆盖临床复核、健康数据质量、监管要求核对及合规审查。

- 类型：Team 型专家团（`expertType: team`）
- 主理人：`med-quality-lead`（质控统筹专家）
- 成员：3 名（临床质控专家、合规审计专家、数据质控专家）
- 技能：11 个（主理人持编排流程，成员按职责分配领域技能；每个成员的可调技能见其 `agents/*.md` 的 `skills` 字段）
- 编排：`agents/med-quality-lead.md` 含成员能力清单、直调路由表与预设 Workflow
- 头像：`avatars/` 下主理人与团队图

## 不适用范围

病案质控与统计指标口径的最终判定、正式统计建模不在本团范围内；本团也不出具伦理委员会审查结论。

# 工作台能力映射（按需查阅）

本页列出本技能所需的能力与本环境中对应的工具名称。**名称不代表当前会话已注册、连接、安装或获授权。** 每次执行前查看当前可用工具与原生说明；仅按说明调用，不根据名称猜参数或返回格式。通用工作流程不依赖这些名称，迁移到其他平台时只需更新本页。

| 所需能力 | 本环境工具 | 使用条件与降级 |
|---|---|---|
| 读取病历文本 | `Read` | 保留原句定位；不在读取阶段改写或归并原文表述。 |
| 读取图片病历、扫描报告 | `ViewImage` | 只转录实际看清的内容；模糊、遮挡或截断处标注不可读，不用一般医学常识补齐。 |
| 读取 PDF 报告 | `workbuddy-pdf` | 按页读取；只取到文本层时说明图表与印章未核。 |
| 渲染草稿与产物 | `Bash` 调本技能 `scripts/` | 依赖 `Pillow`；缺包时降级为纯 Markdown 草稿并说明未生成图片，不临时安装。 |
| 交付草稿 | `Write` + `present_files` | 交付前回读实际产物；缺字段、矛盾信息与不确定断言必须在正文标出，不能用「待医生确认」掩盖。 |

能力之间不互为前提：某一项可用不代表其余项已接入。检索、视觉、文件写入是三种独立能力，不能因一种可用就假定其他能力存在。

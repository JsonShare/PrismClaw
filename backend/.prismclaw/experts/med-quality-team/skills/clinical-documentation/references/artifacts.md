# 文件交付协议

本程序是受控发布器，不是安全沙箱或不可变存储。模型仍可能绕过它；应用必须限制其他写入工具、禁止依赖安装并保存工具审计。

在获准输出位置创建临时工作目录；生成文件成功并核对后运行：
`<已探测的Python绝对路径> <技能目录>/scripts/publish_artifacts.py --root <输出根目录> --input <原始输入文件> --file <待发布文件> [--file <更多文件>]`

程序复制文件到原子创建的 UUID 目录，不复用已存在目录；保留字节与 SHA256、输入指纹、UTC 时间和文件大小。发布后不要再编辑该目录；修改必须新建版本。不要用重建 CSV 冒充原始文件。内联输入先准确保存原文作为输入文件，标记来源为内联。manifest 自身不是数字签名，也无法阻止拥有文件权限的进程事后篡改。present_files 工具只有路径时，附带运行 ID 和 manifest 指纹，不能称平台已绑定不可变版本。

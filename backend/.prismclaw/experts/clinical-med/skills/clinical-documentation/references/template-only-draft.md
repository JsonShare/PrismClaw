# 仅借模板结构成稿

仅适用于医生明确要求“只参考格式、栏目或顺序”的任务。先在内部分开模板结构、本例原文与影响定稿的缺项；不向医生展示额外账本。模板只贡献标题、层级和排列，不贡献患者背景、起病经过、就诊路径、查体、诊断或已执行事项。仅因栏目中存在示例内容，不能把该内容保留进本例。

先按用户明确要求选择栏目，模板中的其他栏目不自动成为本轮任务；要求部分病史、依据和补问，就只交这些内容，不补整套病历、鉴别或检查治疗方案。从本例原文或带原图定位的已核转录建立同一事实记录，再映射到所需栏目。每项事实保留主体、时间、部位、否定和确定性；所需栏目中本例未提供的字段中性留白或列待补，不根据常见病程补连接句。标题及小结也不能暗含未提供的个案信息。重复使用同一事实时不改强度或把“未提供”变成正常、否认、异常、未做。

**诊断依据仍属于事实输出。** 仅整理时只填医生已给评估；同时要求临床分析时，使用`clinical-assessment-workflow`核查后，将推断与已知事实分开。一般疾病特征只能说明判别条件，不能变成本例检查所见；某特征未提供就说明尚需核对，不通过依据段补出它。推断不能反向改写现病史或查体。

交付前对照本例来源回读各栏目及诊断依据：模板示例是否全部隔离、已知关键事实是否保留、同一未知是否在某处被填实。直接交所需病历草稿及少量必要缺项，标明待医生确认；不先交中间记录再另生成病历。

纯内联文字无需代码或文件。明确要求附件时沿用技能文件协议；现有固定源文成稿程序不支持任意模板，不能将普通模板文本冒称为该程序已校验产物。

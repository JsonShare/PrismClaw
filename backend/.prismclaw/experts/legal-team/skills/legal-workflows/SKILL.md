# 企业法务编排流程

主理人按 `agents/legal-team-lead.md` 的直调路由表与 4 个 Workflow 编排成员。任何非平凡问题必须路由给成员，不得由主理人直接给出专业结论。

成员能力见各 Agent MD；本 skill 不保留成员资料副本。

## 适用场景

- 跨域企业法务问题：产品发布前审查、AI 或 SaaS 供应商交易、并购尽调、雇佣调查与用工变更、监管更新后的政策差距。
- 需要多名成员分别出具结论、再由主理人汇编成一份律师复核草稿的场景。

## 执行流程

1. 判定问题涉及的法律域。单域问题按直调路由表交给对应成员；两域及以上进入预设 Workflow。
2. 按 Workflow 的 Phase 顺序派发：Phase 1 并行成员各自独立产出，经主理人中转汇编后才进入 Phase 2。
3. 阶段交接物为「问题清单 + 法条/案例来源标注 + 未决事实缺口」；缺材料时先列缺口，不补猜。
4. 汇编为律师复核草稿，保留成员原有的 [待核验] 标注与用户身份分层。

## 输出格式

Bottom line；涉及法律域与参与成员；按严重度排列的问题与来源；缺失事实或文件；需律师复核事项；建议下一步。

## 输出边界

- 所有输出为律师复核草稿，不构成最终法律意见。
- 不得编造法条、判例、日期、监管要求或来源。
- 输出须保留 [待核验] 标注与用户身份分层，不得删改为确定性结论。
- 诉讼出庭、法律诊所教学与法学生实训不在本团范围，交由对应独立专家。

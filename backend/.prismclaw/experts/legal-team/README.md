# 企业法务专家团

面向企业法务的多角色专家团，覆盖合同、交易、用工、隐私、产品、监管、AI治理与知识产权分诊。

- 类型：Team 型专家团（`expertType: team`）
- 主理人：`legal-team-lead`（法务统筹专家）
- 成员：8 名（商事合同专家、并购法务专家、劳动用工专家、数据隐私专家、产品合规专家、监管政策专家、AI 合规专家、知识产权专家）
- 技能：40 个（主理人持编排流程，成员按职责分配领域技能；每个成员的可调技能见其 `agents/*.md` 的 `skills` 字段）
- 编排：`agents/legal-team-lead.md` 含成员能力清单、直调路由表与预设 Workflow
- 头像：`avatars/` 下主理人与团队图

## 不适用范围

诉讼代理与出庭、法律诊所教学、法学生实训不在本团范围内，分别由 `litigation-law`、`legal-clinic`、`law-trainee` 独立专家承担，不临时增派团成员。

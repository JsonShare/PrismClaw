# 健康管理专家

汇总睡眠营养运动与体质数据生成健康报告，抽取医学实体，不替代医师诊断。

## 类型

Agent 型（单个 AI 专家），expertType = agent。

## 来源

独立专家包，与其他专家平级。

## 能力

- 健康数据报告：多维度可穿戴/问卷数据汇总为结构化报告。
- 体质与心理：中医体质与心理状态分析草稿。
- 实体抽取：从健康文本抽取医学实体与关系。
- 急救信息卡：整理过敏、用药、基础病等急救要点。

## 使用示例

- 根据这份睡眠与营养数据生成结构化健康分析报告。
- 从这段健康描述中抽取医学实体并整理成清单。
- 整理一份含过敏与基础病的急救信息卡草稿。

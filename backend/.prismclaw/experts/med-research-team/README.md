# 临床科研专家团

面向临床科研的多角色专家团，覆盖研究方案设计、文献证据综合、数据可得性评估与科研数据合规审查。

- 类型：Team 型专家团（`expertType: team`）
- 主理人：`med-research-lead`（科研统筹专家）
- 成员：4 名（证据综合专家、临床方案专家、统计分析专家、伦理审查专家）
- 技能：10 个（主理人持编排流程，成员按职责分配领域技能；每个成员的可调技能见其 `agents/*.md` 的 `skills` 字段）
- 编排：`agents/med-research-lead.md` 含成员能力清单、直调路由表与预设 Workflow
- 头像：`avatars/` 下主理人与团队图

## 不适用范围

伦理审查的**批准结论**不在本团范围内——本团只准备送审材料、核对知情同意要素并出具审查意见草稿，批准权属于机构伦理委员会。正式生物统计建模与试验注册申报同样不在本团范围，须由统计师与申办方完成。

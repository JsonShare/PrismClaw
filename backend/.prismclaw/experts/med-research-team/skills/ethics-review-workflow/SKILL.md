# 伦理审查工作流

为涉及人的生命科学和医学研究准备伦理送审材料、核对审查要点，输出**供伦理委员会使用的审查意见草稿**。本技能不作出批准结论。

## 适用范围

- 涉及人的研究：干预性研究、观察性研究、使用人的生物样本或健康数据的研究、涉及人的隐私与行为的研究。
- 跨境合作、数据出境、人类遗传资源采集与保藏，另需按对应管理要求单独核对。
- 动物实验伦理、纯文献综述（不接触人的数据或样本）不在本技能范围。

## 工作流程

### 1. 判定审查方式

按「风险最小 + 是否涉及弱势群体 + 是否涉及敏感个人信息 + 是否干预」逐条对照，判定为**免除审查 / 简易审查 / 会议审查**。

- 免除审查必须**逐条**满足全部条件，不得因「只是观察性研究」直接判免。
- 使用已脱敏的既往临床数据仍可能构成涉及人的研究，需核对数据来源的原始同意范围。
- 判定依据不明确时标 `[待核验]`，交伦理委员会确认，不自行定档。

### 2. 核对送审材料清单

逐项确认是否存在、版本号与日期是否一致：

1. 伦理审查申请表
2. 研究方案（含版本号、日期）
3. 知情同意书（含版本号、日期）
4. 研究者手册或产品说明书（干预性研究）
5. 主要研究者资质与分工授权表
6. 病例报告表或数据采集表单
7. 招募材料（广告、海报、话术）
8. 受试者补偿与保险安排
9. 数据安全与隐私保护方案（含数据保存期限、访问权限、去标识化方式）
10. 涉及生物样本的：采集、储存、使用、销毁与二次使用授权
11. 涉及弱势群体的：额外保护措施说明
12. 利益冲突声明
13. 多中心研究的：牵头单位批件与各中心分工

输出**缺口清单**：缺少哪一项、哪一项版本不一致、哪一项内容与方案矛盾。

### 3. 逐条核对知情同意书

按以下要素逐条核对，缺失或含糊的列为修改意见：

- 研究目的与背景，用受试者能理解的语言说明
- 研究流程、随访次数、每次耗时、需配合的事项
- 可预见的风险、不适与不便，以及应对措施
- 预期受益：**无直接受益时必须明确写出**
- 替代方案（如存在）
- 自愿参加与**随时退出且不影响常规诊疗**的表述
- 隐私保护：谁可接触数据、如何去标识化、保存多久、结果如何发表
- 生物样本与数据的二次使用：是否单独授权、可否撤回、撤回后的处理
- 补偿与费用承担，含发生损害时的处理与联系方式
- 联系人：研究者姓名与电话、伦理委员会联系方式与投诉渠道
- 语言与可读性：避免术语堆砌，长度与阅读难度适配目标人群

### 4. 审查要点

- **科学价值与社会价值**：研究问题是否成立，方案能否回答该问题（交 `clinical-advisor` 核方案可行性）
- **风险受益比**：风险是否最小化，受益是否相称
- **受试者选择的公正性**：负担与受益是否落在同一人群，是否过度依赖易受压力人群
- **弱势群体额外保护**：儿童、孕妇、精神障碍者、认知障碍者、囚犯、学生与下属、经济弱势者
- **隐私与数据安全**：最小必要采集、去标识化、访问控制、留存期限、出境合规
- **利益冲突**：研究者与申办方关系、报酬安排是否影响判断
- **跟踪审查**：修正案、年度/定期报告、方案偏离、严重不良事件报告路径

### 5. 输出

- 审查方式判定与依据（含不确定项）
- 送审材料缺口清单（可勾选）
- 知情同意书逐条核对表（符合/需修改/缺失 + 具体改法）
- 审查意见草稿：**同意 / 修改后同意 / 需进一步说明 / 不同意** 四档，并给出理由与整改要求
- 需提交伦理委员会确认的事项清单

## 红线

- **不作出「已通过伦理审查」的结论**。批准权只属于伦理委员会；本技能只输出草稿与缺口清单。
- 不得因研究「看起来风险低」而跳过免除审查的逐条对照。
- 涉及弱势群体时不得省略额外保护措施，缺措施即为不通过项。
- 涉及数据出境、跨境合作、人类遗传资源时，先确认适用要求；不明确时标 `[待核验]`，不臆断可行。
- 法规名称、版本与生效日期须核对当前有效版本；不凭记忆引用条号，无法核实时标注 `[待核验]`。
- 知情同意书中的受益、风险、补偿不得由本技能「润色」为更强表述；只做核对与补缺。

## 与团队协作

- 方案可行性、临床适用性 → 交 `clinical-advisor`
- 样本量与统计方法是否支撑结论 → 交 `data-analyst`
- 证据等级与文献依据 → 交 `research-counsel`
- 结论回传主理人汇编，不直接对外发布

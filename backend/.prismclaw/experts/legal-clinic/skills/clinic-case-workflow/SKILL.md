# clinic-case-workflow

## 场景分流

按用户意图匹配以下场景，严格按声明顺序调用对应原子技能：

**法律文书起草（诉/辩/代，含格式化文书与申请表格）**
按目标、受众、事实结构起草法律文书，并批量填写法院格式化文书与申请表格。
→ `skills/legal-clinic-playbook/references/commands/draft.md`

**法律研究备忘录 Memo**
Issues + Brief Answers + Discussion + Conclusion 结构 memo。
→ `skills/legal-clinic-playbook/references/commands/memo.md`

**法律研究路线启动**
决定检索工具、关键词、法规库、二次文献。
→ `skills/legal-clinic-playbook/references/commands/research-start.md`

**期限/时效/庭期追踪**
法定期限、约定期限、法院庭期统一看板与提醒。
→ `skills/legal-clinic-playbook/references/commands/deadlines.md`

**案件状态与阶段性报告**
给客户/指导老师的进度看板和状态摘要。
→ `skills/legal-clinic-playbook/references/commands/status.md`

若场景模糊，先向用户澄清匹配哪一分支，不要盲跳步骤。

## 输出规范

### 来源标注（citation）
所有结论附来源条目编号。引用合同、法规、通信原文时，格式为：
`[序号] 文件名:行号 | 原文片段或条款编号`

示例：
- `[1] 供货合同.pdf:第4.2条 | 买方应于收到发票后30日内付款`
- `[2] 民法典.pdf:第577条 | 当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任`
- `[3] 2024-03-15对方邮件.eml:L12-15 | "我方将于本月底安排付款"`

引用判例时标注案号：`[4] (2023)京01民终12345号判决书:L45-50`

### 输出格式（formatter）
所有最终输出严格分四段，每段独立成章：

1. **结论** — 你判断的事项核心观点、建议采取的下一步动作（一句话 + 详细展开）
2. **依据** — 支撑结论的合同条款、法律规定、证据要点（逐条列出，附来源标注）
3. **风险** — 不按建议行动的后果、对方可能的抗辩、时效/程序风险（逐条列出，附触发条件和概率）
4. **来源** — 本回复所依据的全部材料清单，对应依据段落的 `[序号]` 引用

草稿阶段（未最终确认前）允许插入 `[PLACEHOLDER——待核实:____]` 占位符，但必须标明确切待核实点与负责角色。

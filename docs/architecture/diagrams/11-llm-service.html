LLM Service Architecture

Factory → ProviderResolver → StreamFn → PromptOptimizer — Call chain with retry, fallback, and SOP extraction

LLM Call Chain

  • • Factory → ProviderResolver → StreamFn
  • • 3x retry: stream → stream → complete (fallback)
  • • Tool call arg sanitization for malformed JSON
  • • Qwen thinking auto-disable on non-DashScope

Provider Resolution

  • • 5-level matching: exact → prefix → segment → single → policy
  • • Credential resolution: api_key + api_base + provider
  • • Error classification: 5 error codes
  • • Vision model detection and routing

SOP & Skill Pipeline

  • • SOP extraction: Redis SETNX → LLM → FTS5+Jaccard dedup
  • • Skill graduation: L3 SOP → SKILL.md with backup
  • • PII/credential detection in SOP validation
  • • PromptOptimizer: LLM rewrite at temp=0.3

Dreaming 引擎 Architecture

Scheduler → Queue → Engine(3-phase) → Compiler → Governance

三阶段处理模型

  • • Light: L1→L2 提升，零 LLM 去重
  • • Deep: Mid(衰减+降级) + Deep(语义合并)
  • • REM: 归档合成 + 制品发布 (≤12项)
  • • Light 最小间隔 12h

Dream Compiler

  • • Publish Gate: content≥8, conf≥0.72, steps≥2
  • • Merge Judge: duplicate/refine/contradict/new
  • • 版本链解析: _resolve_version_chain_id
  • • 候选提取 → 门控 → 判决

Dream Governance

  • • Shadow: 不存储，仅观察
  • • Canary: 灰度存储 + hash-percent rollout
  • • Direct: 直接发布
  • • 审批 / 拒绝 / 回滚完整流程

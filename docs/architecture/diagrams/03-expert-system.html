Expert System Architecture

专家 / 专家团 / 技能 / MCP 连接器 — 会话意图 → 环境快照 → 作用域 → 人格注入与工具面裁剪 → 执行与治理

四个一级概念

  • • 专家 Expert：人格 + 工具面，一次会话内唯一
  • • 专家团 Team：lead + 成员，成员之间不可互连
  • • 技能 Skill：规范标识 {expert}:{skill}
  • • MCP 连接器：部署级注册表，仅返回 enabled

关键不变量

  • • SessionHeader.expert_id 单值、互斥，取消即清空
  • • 只有 user 显式选择可以激活专家
  • • 一次 run 只构建一个三态 Scope
  • • tool_owners 为包级口径，不做逐技能集合
  • • MCP 工具不参与专家工具面裁剪

生命周期与热更新

  • • uninstalled → installed → loaded → active
  • • active ↔ inactive；unload 回到 installed
  • • ReleaseDocument 经 ModuleRuntimeCoordinator 热更新
  • • 重建 EnvironmentCatalog 后下一次 run 生效

边界约束 Constraints

  • • 专家是会话属性：同一会话至多一个，只有用户显式选择可激活
  • • 专家包禁止 hooks / MCP / commands / LSP 声明
  • • MCP 是部署级连接器，不参与专家工具面裁剪
  • • 启停只读 capability_policy，运行期不改包内容
  • • 子代理不换专家、不派发同级成员

PrismClaw Architecture

5-Layer Dependency Architecture · L0 Schema → L1 Engine → L2 Runtime → L3 Assembly → L4 App

Schema · 契约层 (L0)

  • • 8 of 16 pure type modules: agent, llm, services, content, config, session, storage, memory
  • • Zero external dependencies — all other layers depend on L0
  • • Defines shared interfaces, DTOs, and domain contracts
  • • Any breaking change here propagates to all upper layers

Engine · 引擎层 (L1)

  • • 15 functional modules organized in 4 rows
  • • Row 1: 执行引擎, 沙箱安全, 技能系统, 插件系统
  • • Row 2: 记忆系统, Dreaming引擎, 上下文压缩, MCP集成
  • • Row 3: 子代理, 工具集, LLM服务, 审查系统
  • • Row 4: 运行时管理, 调度器, 策展器

Runtime · 运行时层 (L2) & Assembly · 编配层 (L3) & App · 通信层 (L4)

  • • L2: 4 DI bundles — Infrastructure, Runtime, Lifecycle, AgentRunnerDeps
  • • L3: WebSocket, Auth/JWT, Gateway, HTTP Routes, ChatRunner
  • • L2 wires L1 modules; L3 exposes them to the outside world
  • • PG persistence: memory, session, trajectory, audit, dream, scheduler, workspace

审查系统 Architecture

Event-Sourcing (ReviewSet → Event → ContentStore) · Policy Dispatch · Atomic Materialization

Event-Sourcing 模式

  • • ReviewSet 纯状态容器，不执行 IO
  • • ReviewEvent append-only，永不原地修改
  • • 事件溯源重建: rebuild() 从事件流恢复状态
  • • materialized 事件审计物化操作

ContentStore 完整性

  • • Content-addressable: blobs/<sha256>
  • • get() 每次重新校验 SHA-256
  • • 原子写入: .tmp → replace
  • • IntegrityError 杜绝静默损坏

策略分派 + 原子回滚

  • • TextChange: 整文件回滚到 baseline
  • • SpreadsheetChange: 精细反转 rejected 操作
  • • DocxChange: tracked-changes 产物模式
  • • materialize_file(): temp→fsync→os.replace 原子写入

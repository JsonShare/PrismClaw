Web Layer Architecture

WebSocket → Chat → Auth → Gateway → Routes — Processing chain with session affinity and multi-worker routing

WebSocket + Chat

  • • WS: identify → JWT → heartbeat + dispatch
  • • ChatRunner: single-pass instant delta + full transcript
  • • chat.done exponential backoff (8 retries)
  • • try_handle_slash_command(): slash command interception

Gateway Routing

  • • AffinityRegistry: Redis NX+TTL, Lua atomic release
  • • Forwarder: Pub/Sub cross-worker messaging
  • • WorkerRegistry: sorted set heartbeat (30s)
  • • force_claim on forward failure

Auth + Middleware

  • • HS256 JWT with 24h expiry
  • • PG user store with config fallback
  • • CSP, HSTS, rate limit 100/min
  • • Prometheus + OpenTelemetry tracing

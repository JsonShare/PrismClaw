调度器 Architecture

Engine → 幂等门 → Notification → Consumer → Executor · at-most-once · 主链路复用

四层架构

  • • Layer 1: SchedulerEngine — 1s tick 调度
  • • Layer 2: 一次性唤醒信号 — XADD / XREADGROUP / 读后即 XACK
  • • Layer 3: Consumer — 每节点本地 semaphore 背压
  • • Layer 4: ScheduledRunExecutor — 调度状态机 + 复用主链路执行

Leader Election + 缓存

  • • LockManager: 2s续约 / 5s TTL / 3s容错
  • • nextFireAt: 进程内缓存 + Redis pub/sub
  • • _cache_dirty: 连接断开时兜底全量重建
  • • _redis_ping_loop: 30s PING 保活

幂等与崩溃语义

  • • run.id = sha256(task_id:fire_slot)[:16]
  • • add_run: ON CONFLICT DO NOTHING → 赢家才 XADD
  • • 读后即 ACK: 无 PEL / 无 XAUTOCLAIM / 无死信
  • • 崩溃停在 pending/running，不自动补跑

主链路复用 + 熔断

  • • cron 只是触发方式，不是另一套执行 mode
  • • 消息 / 时间线 / 交付物由主链路统一落库
  • • 不做定时专用工具策略 / 轮次上限 / 执行超时
  • • 跨节点帧: 本地优先，无本机连接才转发一次
  • • 熔断器: 连续失败 → 自动 disabled

Toolkit Architecture

Builtin Tool Layer + File Infrastructure Layer — Dual-layer data flow with optimistic concurrency control

Write Tools (tool_class=write)

  • • BashTool: persistent PTY, 15s budget, soft/hard timeout
  • • WriteTool: binary block, review registry, epoch track
  • • EditTool: string replace, Python syntax check
  • • CancelTaskTool: skill-gated, ParallelTaskStore

Read Tools (tool_class=read)

  • • ReadTool: 2000-line pages, SHA-256 read_epoch
  • • ListDirectoryTool: runtime.fs_list()
  • • AskUserQuestion: interactive, 1-4 Qs

File Infrastructure

  • • FileObserver: SHA-256 version tracking + OCC
  • • FileMutationQueue: per-file asyncio.Lock
  • • GlobTool/GrepTool: pattern/content search
  • • OCR Cache: stat fingerprint, auto-invalidate

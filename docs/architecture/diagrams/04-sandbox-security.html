Sandbox & Security Architecture

SafetyGate decision pipeline → BwrapPolicy execution — fail-closed multi-layer defense

SafetyGate Pipeline

  • • 6-step evaluation: L0 static → L1 risk → mode → consent → L2 confirm → tenant
  • • RuleGate: 5 static rules (path/SSRF/tag/MCP)
  • • RiskRouter: 3D cross (scope × classification × reversibility)
  • • ConfirmGateway: SOFT_BATCH / HARD_MFA / HARD_4EYES

Sandbox Isolation

  • • BwrapPolicy: Linux bubblewrap process isolation
  • • Readonly /usr, bind workspace, tmpfs /tmp, PID isolation
  • • STRICT tier: --unshare-net + clearenv + setenv whitelist
  • • Hardcoded deny: /root, /home, /etc/ssh, /etc/ssl/private

DLP & Compliance

  • • 4-step scan: preprocess → regex → k-anon → byte ratio
  • • k-anonymity: ≥30 PHI rows → BLOCK
  • • PHI byte ratio: ≥30% outbound → BLOCK
  • • WORM: SHA256 hash chain + S3 Object Lock 7yr + Fanout

MCP 集成 Architecture

MCPClientManager(5-Mixin) → Adapter → NetworkACL

5-Mixin Architecture

  • • Config: sandbox policy + per-server telemetry
  • • Connection: connect/restart/death handling
  • • Lifecycle: non-blocking supervisor
  • • Registry: attach/register + log redaction
  • • Adapter: dual-name (J1) builder

MCPToolAdapter (J1)

  • • name: server:tool (registry key)
  • • _sdk_key: SDK dispatch (execute uses this)
  • • Content: Text/Image/Audio/Embedded
  • • Dead server: ClosedResource/Broken/EOF
  • • Timeout + McpError handling

McpNetworkAcl (Fail-Closed)

  • • Default policy: deny-all
  • • Global whitelist + per-server domains
  • • fnmatch wildcard matching
  • • Unregistered server always DENIED
  • • Built-in: his/rms/email defaults

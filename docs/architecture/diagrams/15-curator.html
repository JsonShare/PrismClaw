策展器 Architecture

CuratorCycle (scan + review) · DistributedMutex · StateStore · Dreaming 引擎维护工兵

CuratorCycle 单次执行

  • • 不可复用：每个 cycle 需要新实例
  • • 扫描: 归档过期 SOP + 升级高频 SOP
  • • 审查: LLM 质量评估 keep/promote/archive
  • • 并发扫描: SCAN_CONCURRENCY = 10

DistributedMutex 保护

  • • curator:cycle 锁键
  • • acquire → check_alive 关键点检查
  • • 锁丢失时立即停止，标记 error="lock_lost"
  • • 缩小 UPDATE 竞争窗口

CuratorStateStore 持久化

  • • Redis: prismclaw:curator:last_run_at
  • • Redis: prismclaw:curator:llm_review_last_run_at
  • • seed_if_missing() NX 初始化
  • • 跨实例共享状态，唯一写入者

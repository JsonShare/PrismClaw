Plugin System Architecture

Discovery → Load → Ingest → Activate lifecycle — 3 dialects, trust hierarchy, hook system with circuit breaker

Lifecycle Management

  • • 4-phase: Discovery → Load → Ingest → Activate
  • • 3 load strategies: NativePython / Declarative / Trae
  • • 3 dialects: CANONICAL / TRAE / BARE_SKILLS
  • • Source dir never modified; canonical copy output

Trust & Sandbox

  • • 3-tier trust: TRUSTED / VERIFIED / UNTRUSTED
  • • Dual-gate: source policy + workspace trust
  • • SandboxPolicy: paths, commands, network, memory
  • • PluginSandbox: validate_command / validate_path / build_safe_env

Hook System

  • • 4 handler types: ShellCommand / HTTP / Callback / Matcher
  • • CircuitBreaker: CLOSED → OPEN → HALF_OPEN
  • • Per (plugin_id, event_name, hook_id) isolation
  • • Shell env injection + variable substitution + 30s timeout
